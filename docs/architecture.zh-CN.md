# 架构

[English](architecture.md) | 简体中文

DSH Cloud 在 DeepSeek Harness 智能体运行时外围提供账号、策略、计量、模型网关和
可选浏览器工作区。同一套公开服务既可由用户自部署，也可通过 DSH Cloud Hosted
使用。本文描述仓库接口，不披露任何线上环境的拓扑、容量、凭证或提供方配置。

## 系统上下文

```text
浏览器 / 桌面 / 移动客户端
          | HTTPS + 会话或设备凭证
          v
    反向代理 / TLS 入口
          v
   FastAPI 应用 (:8100) ---- 运营方选择的模型/搜索上游
      |        |
      |        +---- 账号、团队、套餐、管理、Web 控制台和模型网关
      +---- SQLite 或 PostgreSQL
      +---- 可选工作区后端 ---- 智能体运行容器
```

标准 Compose 中只有反向代理面向公网。应用在内部网络监听 `8100`；上游模型凭证
始终留在服务端，客户端只得到可撤销的账号、设备或 API 凭证。

## 组件与探针

`server/app/main.py` 组装 FastAPI 服务，路由覆盖账号、OAuth、设备授权、模型网关、
支付、团队、管理、桌面更新、工作区和服务端页面。

- `GET /livez`：进程存活；
- `GET /readyz`：数据库与关键配置就绪；
- `GET /version`：发行版本与修订；
- `GET /api/health`：兼容性存活端点。

流量切换必须看 `/readyz`，不能把只表示进程存活的端点当成就绪检查。

## 身份、网关与数据

浏览器使用 HTTP-only Cookie，桌面端使用设备授权，API key、设备凭证和会话均可
吊销。认证后仍需通过账号状态、团队角色、套餐、额度、速率和路由级授权。

模型网关验证调用者和模型 ID，执行额度与并发策略，把客户端凭证替换为服务端上游
凭证，流式转发响应并记录标准化用量。业务数据保存在 SQLite 或 PostgreSQL；生产
备份、恢复和迁移必须由运营方验证。

## 工作区信任边界

工作区执行用户控制的代码，默认关闭。容器、共享网络和 Docker socket proxy 不是
天然的恶意多租户隔离边界。公网启用前必须评估镜像、网络、挂载、权限、出网、预览、
凭证和资源限制。详见 [安全指南](security.zh-CN.md) 与
[伸缩指南](workspace-scaling.zh-CN.md)。
