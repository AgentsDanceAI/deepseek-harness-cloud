# 发行清单

[English](release-checklist.md) | 简体中文

此清单用于准备证据，不自行授权发布或部署。

## 身份与范围

- [ ] 版本和源码修订来自统一发行元数据，并在服务器、容器、npm、Python 和文档中一致。
- [ ] 变更日志与已验证变更一致，不重构无法证明的历史。
- [ ] 当前许可证、声明、源码归档和版本边界已审查。
- [ ] 发行树不含凭证、个人/客户数据、私有运维材料或构建垃圾。

## 验证

- [ ] 全量测试、JS 测试、lint/format 和文档检查在干净 checkout 中通过。
- [ ] Docker/Compose 在支持架构完成 smoke test。
- [ ] npm/npx 与 uv/uvx 通过等价契约和 dry-run。
- [ ] 使用一次性数据验证数据库升级、备份、恢复和回滚。
- [ ] 生成并验证 SBOM、来源证明、校验和、签名及产物到源码的映射。
- [ ] 安全审查覆盖依赖、请求边界、密钥、认证授权、webhook、预览和工作区。

## 发布门禁

- [ ] 已独立验证 Registry 名称空间、OIDC/可信发布者、受保护环境、维护者与恢复联系人。
- [ ] 获授权发行负责人批准精确版本、哈希/digest、目标和恢复方案。
- [ ] 只有不可变产物通过消费者验证后才移动浮动标签。
- [ ] 发布不等于生产部署；生产上线需独立备份、观察和回滚证据。
