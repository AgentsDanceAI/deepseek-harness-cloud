# Maintainer handbook

English | [简体中文](README.zh-CN.md)

These documents govern repository changes without recording live credentials,
private topology, customer data, capacity, cost, or incident details.

- [Documentation review](documentation-review.md)
- [Release checklist](release-checklist.md)

External actions are separate from repository work. A local code change does not
authorize a production deployment, registry publication, GitHub settings change,
license replacement, or public-history rewrite.
