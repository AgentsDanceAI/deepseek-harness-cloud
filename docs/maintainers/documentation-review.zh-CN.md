# 文档审查

[English](documentation-review.md) | 简体中文

- [ ] 每条命令存在于同一候选树，并在一次性环境或明确的 dry-run 中执行过。
- [ ] 包和镜像示例固定不可变版本；未发布产物不得伪装成可安装状态。
- [ ] Hosted 链接只使用获准的登录、个人套餐和团队套餐 URL。
- [ ] Hosted 使用积极、准确的托管订阅表述，并说明所选周期一次性付费且不自动续费。
- [ ] 自部署文档保持中立，操作步骤中不反复插入营销文案。
- [ ] 许可证使用 `LicenseRef-DSH-Cloud-Community-1.0`，限制使用方式和商业联系路径
      与 `LICENSE`、`LICENSING.md` 一致。
- [ ] 不包含生产标识、私有地址、用户资料、凭证、容量/成本记录、备份切换说明或事件日志。
- [ ] 相对链接、锚点、图片说明、标题、拼写及英文/中文入口均已检查。
- [ ] 安全说明只陈述已实现控制和剩余风险，不声称认证、完美隔离或无依据的 SLA。
