# License transition gates

The active repository license is AGPL-3.0-only. No maintainer may replace it or
describe a planned source-available license as effective while any gate in
`legal/licensing/LICENSE_STATE.toml` is false.

Required independent evidence:

1. qualified counsel approves final operative text and public description;
2. the exact release tree has a complete, reviewed copyright and provenance
   inventory;
3. third-party licenses, notices, and compatibility are verified;
4. contribution terms and contributor notice are approved;
5. the Community baseline and non-paywalled security/export/backup boundary are
   verified; and
6. a release owner authorizes the exact prospective version and artifacts.

Already distributed AGPL versions keep their granted rights. A future change can
apply only prospectively and only to material the licensor has authority to
relicense. Counsel evidence belongs in an access-controlled system; public files
contain only non-secret review identifiers and conclusions.
