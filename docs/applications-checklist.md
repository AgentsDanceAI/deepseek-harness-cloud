# DSH Cloud 上线申请清单

版本 1.0，生效日期【上线日期】

> 本清单为亲自办理各项申请的操作指引。周期与费用为撰写时的经验值，以各平台实时页面为准；涉及合规判断的条目已标注 **需咨询专业意见**。申请主体统一使用【运营主体】营业执照（当前为北京跃迁效应人工智能科技有限公司）。

## (a) 域名与备案

### a1. 域名购买

| 项 | 内容 |
|---|---|
| 官方入口 | 阿里云万网 <https://wanwang.aliyun.com>（或腾讯云 <https://dnspod.cloud.tencent.com>） |
| 需准备材料 | 企业支付账号；域名实名认证需营业执照 |
| 预计周期 | 购买即时；企业实名认证约 1 个工作日 |
| 费用 | .com 约 ¥60–80/年 |
| 依赖 | 无（一切的起点） |

要点：若走阿里云 ICP 备案，域名放在阿里云名下最省事（同账号直接关联）。同时把 API/控制台规划为子域名（如 `api.域名`、`console.域名`），备案是按域名主体级别的，子域名不需单独备案。

### a2. ICP 备案（阿里云流程）

| 项 | 内容 |
|---|---|
| 官方入口 | <https://beian.aliyun.com>（工信部查询 <https://beian.miit.gov.cn>） |
| 需准备材料 | 营业执照、法人身份证、负责人手机号（在线核验/人脸）、阿里云中国内地服务器产生的**备案服务号**（需购买中国内地 ECS/轻量服务器，通常要求包月 3 个月以上）、网站名称与内容说明 |
| 预计周期 | 阿里云初审约 1 个工作日 + 短信核验 + 各省管局审核（北京通常 1–2 周，法定上限 20 个工作日） |
| 费用 | 备案免费；服务器费用另计 |
| 依赖 | a1 域名（且域名实名主体须与备案主体一致） |

要点与技巧：

- **备案审核期间域名不得开站**（解析出可访问的网站会被驳回）。
- **独立静态备案站技巧**：准备一个极简静态官网页（产品介绍 + 底部悬挂 ICP 备案号链接到 miit.gov.cn），作为备案对应的"网站"。产品控制台/网关走子域名，与这个静态页解耦——产品随便迭代，备案对应的展示面始终稳定合规，也避免审核期间被要求"网站内容与备案信息不符"整改。
- 网站名称不要带"云""平台"等易被要求前置审批的敏感词组合，用产品名即可；网站服务内容如实填写"软件工具官网/客户端下载"。
- 经营性 ICP 许可证（ICP 证）与普通备案不同：向不特定用户收费的在线服务是否构成"经营性互联网信息服务"，各地口径不一，**需咨询专业意见**。

### a3. 公安备案

| 项 | 内容 |
|---|---|
| 官方入口 | 全国互联网安全管理服务平台 <https://beian.mps.gov.cn>（原 www.beian.gov.cn） |
| 需准备材料 | ICP 备案号、营业执照、法人与网站负责人身份证、网站信息；部分地区需线下核验 |
| 预计周期 | 网站**开通之日起 30 日内**必须提交；审核数日至 2 周 |
| 费用 | 免费 |
| 依赖 | a2 ICP 备案通过且网站已上线 |

通过后须在网站底部悬挂公安备案号（与 ICP 备案号并列）。

## (b) 支付

### b1. Stripe（面向海外用户收款）

| 项 | 内容 |
|---|---|
| 官方入口 | <https://dashboard.stripe.com/register>；主体设立可参考 Stripe Atlas <https://stripe.com/atlas> |
| 需准备材料 | **Stripe 不支持中国大陆主体直接开户**——需香港/新加坡/美国等地的公司主体 + 当地银行账户 + 身份证明。若无海外主体，需先设立（如 Stripe Atlas 注册美国公司）或暂缓此渠道 |
| 预计周期 | 已有海外主体：注册当天可收款，激活审核数天；无海外主体：设立主体 2 周起 |
| 费用 | 开户免费；费率约 2.9% + $0.30/笔（跨境/换汇另加，以官网为准）；Atlas $500 一次性 |
| 依赖 | 海外主体；webhook 需一个 HTTPS 回调地址（不要求 ICP 备案，可用任意域名） |

### b2. 支付宝开放平台 —"电脑网站支付"签约

| 项 | 内容 |
|---|---|
| 官方入口 | <https://open.alipay.com>（创建"网页/移动应用"）+ 商家平台 <https://b.alipay.com>（产品签约） |
| 需准备材料 | 营业执照、法人支付宝账号/对公账户、**已 ICP 备案的网站**（审核会核对网站可访问且悬挂备案号、内容与经营范围相符） |
| 预计周期 | 1–3 个工作日 |
| 费用 | 签约免费；费率一般 0.6% 左右（以签约页为准） |
| 依赖 | a2 ICP 备案 + 网站上线；回调（异步通知）地址须为公网 HTTPS |

### b3. 微信支付商户号 + APIv3（Native 支付）

| 项 | 内容 |
|---|---|
| 官方入口 | <https://pay.weixin.qq.com>（申请普通商户号 → 产品中心开通"Native 支付"） |
| 需准备材料 | 营业执照、法人身份证、对公账户（打款验证）、**已 ICP 备案的网站**；开通后配置 APIv3 密钥、商户证书/平台证书 |
| 预计周期 | 商户号审核 1–5 个工作日；Native 产品开通通常即时至数日 |
| 费用 | 免费开户；费率一般 0.6% |
| 依赖 | a2 ICP 备案 + 网站上线；回调地址须为公网 HTTPS 域名 |

三渠道共同要点：回调/webhook 域名要提前定稿（支付宝、微信要求填写在应用配置里），建议统一 `api.域名` 并在备案通过后尽早部署 HTTPS。

## (c) 邮件（验证码与通知）

| 项 | 内容 |
|---|---|
| 官方入口 | 阿里企业邮箱 <https://qiye.aliyun.com> 或腾讯企业邮 <https://exmail.qq.com>（均有免费版）；亦可用事务邮件 SMTP 服务 |
| 需准备材料 | 域名管理权限（配置 MX 记录）；发信域名务必配齐 **SPF、DKIM、DMARC** 三条 DNS 记录，否则验证码大概率进垃圾箱 |
| 预计周期 | 开通即时；DNS 生效数小时 |
| 费用 | 免费版可用；付费版约 ¥50/账号/年起 |
| 依赖 | a1 域名 |

要点：验证码发信建议用独立子域（如 `mail.域名`），与企业办公邮箱隔离，避免互相影响信誉度。服务端 SMTP 参数即 `server/` 的邮件配置项。

## (e) 代码签名

### e1. Apple Developer（macOS 分发）

| 项 | 内容 |
|---|---|
| 官方入口 | 注册 <https://developer.apple.com/programs/enroll/>；D-U-N-S 查询/申请 <https://developer.apple.com/enroll/duns-lookup/> |
| 需准备材料 | 公司 **D-U-N-S 编码**（没有可经 Apple 通道免费申请，约 5 个工作日）、公司法定名称与官网、可验证的联系人；注册组织账号会有 Apple 电话核实 |
| 预计周期 | D-U-N-S 约 1 周 + 组织账号审核 1–2 周 |
| 费用 | $99/年；D-U-N-S 免费 |
| 依赖 | 无（可与备案并行，尽早启动） |

拿到账号后：创建 **Developer ID Application 证书**签名 Electron 安装包，并走 **notarytool 公证**（自动化、通常分钟级），否则 macOS Gatekeeper 拦截。

### e2. Windows 代码签名证书

| 项 | 内容 |
|---|---|
| 官方入口 | CA 商购买：DigiCert <https://www.digicert.com> / Sectigo <https://sectigo.com> / SSL.com <https://www.ssl.com>；或 Azure Trusted Signing <https://azure.microsoft.com/products/trusted-signing> |
| 需准备材料 | 企业验证（营业执照、邓白氏或官方电话回拨）；2023 年起 OV/EV 私钥均须硬件介质或云 HSM（CA 提供云签名方案） |

| 依赖 | 无（可并行）。EV 证书对 SmartScreen 信誉冷启动更友好；OV 需要下载量积累信誉 |

> 本节整体标注：**需咨询专业意见**。以下仅为申请入口与背景信息，不构成合规判断。

| 项 | 内容 |
|---|---|
| 入口 | 互联网信息服务算法备案系统 <https://beian.cac.gov.cn>（网信办） |
| 背景 | 《生成式人工智能服务管理暂行办法》《互联网信息服务算法推荐管理规定》《深度合成管理规定》要求"具有舆论属性或社会动员能力"的生成式 AI 服务履行算法备案/大模型备案（上架）义务 |

| 待办 | 1）整理"技术定位说明"（仅网关转发、上游模型已备案的证明材料）；2）咨询属地网信办或专业律师确定：完整备案 / 登记 / 豁免；3）产品内按要求展示相应备案/登记编号与 AI 生成内容标识（《人工智能生成合成内容标识办法》） |

## 上线顺序总表（依赖排序）

| 序 | 时间窗 | 事项 | 依赖 | 关键输出 |
|---|---|---|---|---|

| 2 | 第 0 周（并行） | 企业邮箱/SMTP 开通，配 SPF/DKIM/DMARC | 域名 | 验证码发信能力 |
| 3 | 第 0 周（并行） | D-U-N-S 申请 → Apple Developer 组织账号；Windows 签名证书下单 | — | 签名/公证能力 |
| 4 | 第 0 周（并行） | DeepSeek 平台充值拿 key；评估备用上游（境外上游触发隐私政策跨境条款） | — | `UPSTREAM_API_KEY` |
| 5 | 第 0–1 周（并行） | **启动 (g) 生成式 AI 合规咨询**（周期最不可控，最早启动） | — | 备案/登记/豁免结论 |
| 6 | 第 1–3 周 | 提交 ICP 备案（挂极简静态备案站方案）；审核期间域名不开站 | 1 | ICP 备案号 |
