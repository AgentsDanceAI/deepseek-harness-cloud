# Support

English | [简体中文](SUPPORT.zh-CN.md)

Choose the route that matches your request. Public support is community-based
and has no response-time commitment unless a separate agreement says otherwise.

| Request | Channel | Notes |
|---|---|---|
| Reproducible Community Edition bug | [GitHub Issues](https://github.com/AgentsDanceAI/deepseek-harness-cloud/issues) | Search first; use the bug form and remove secrets and personal data. |
| Feature or design proposal | [GitHub Issues](https://github.com/AgentsDanceAI/deepseek-harness-cloud/issues) | Use the feature form and identify the edition-boundary impact. |
| Installation or configuration help | [GitHub Issues](https://github.com/AgentsDanceAI/deepseek-harness-cloud/issues) | Include version, platform, redacted configuration, and diagnostics. |
| Security vulnerability | [Private security report](https://github.com/AgentsDanceAI/deepseek-harness-cloud/security/advisories/new) or [security@agentsdance.ai](mailto:security@agentsdance.ai) | Never disclose an unpatched vulnerability publicly; see [SECURITY.md](SECURITY.md). |
| Hosted account, order, refund, or billing | [support@agentsdance.ai](mailto:support@agentsdance.ai) | Send the account email and order reference; never send a password, session token, or payment credential. |
| Commercial support, Enterprise, or separate licensing | [support@agentsdance.ai](mailto:support@agentsdance.ai) | Use subject `Commercial licensing` and describe organization size, deployment model, and required controls. |
| Trademark or legal request | [legal@agentsdance.ai](mailto:legal@agentsdance.ai) | Include the relevant product, document, or proposed use. |

## DSH Cloud Hosted

[DSH Cloud Hosted](https://dshcloud.online/login?next=%2Fwork) is a managed
subscription service. Individual and team offerings include managed model access,
workspace capacity, upgrades, monitoring, backups, account support, and plan
allowances. Current public offers are paid once for the selected monthly or annual
term and **do not renew automatically**.

- [Individual plans](https://dshcloud.online/pricing#plans)
- [Team plans](https://dshcloud.online/pricing#team)

The checkout page and Hosted terms control a specific purchase. Do not include
payment card data or credentials in a support request.

## Self-hosted support boundary

Community support covers reproducible behavior in this repository. Operators
remain responsible for host security, DNS and TLS, upstream model providers,
email and identity providers, payment providers, data retention, backups,
monitoring, and local legal obligations. A minimal reproduction should use the
documented configuration and synthetic data.
