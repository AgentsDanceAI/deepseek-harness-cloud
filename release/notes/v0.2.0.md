# DSH Cloud 0.2.0

DSH Cloud 0.2.0 is the first coordinated public release of the self-host stack,
version-locked npm and Python installers, server and workspace images, bilingual
documentation, and release provenance contracts.

Highlights:

- one-command local trials with npm/npx or uv/uvx;
- canonical Docker Compose deployment with SQLite or PostgreSQL;
- pinned server and workspace images with embedded source revision;
- hardened authentication, webhook, request-size, streaming billing, preview,
  container, and upgrade boundaries;
- DSH Cloud Community License 1.0; and
- reproducible CLI packages, checksums, SPDX SBOM, and GitHub attestations.

See [CHANGELOG.md](https://github.com/AgentsDanceAI/deepseek-harness-cloud/blob/v0.2.0/CHANGELOG.md),
[installation](https://github.com/AgentsDanceAI/deepseek-harness-cloud/blob/v0.2.0/docs/install.md),
and [self-host deployment](https://github.com/AgentsDanceAI/deepseek-harness-cloud/blob/v0.2.0/docs/deploy.md).
