# DSH Cloud 0.2.4

一行命令，一个能看的站点。

## 优化改进

- 试用模式（`start` 的默认）**不再提任何问题**。此前会问模型上游、API Key
  和搜索 Key——但试用站点上能看的东西（桌面端下载、云工作台）本来就指向
  官方站点 dshcloud.online，本机根本用不到上游密钥。配置面是 `.env` 这个
  文件，不是一串问号：想在本机真跑模型的人去填 `UPSTREAM_API_KEY`，再执行
  一次启动命令即可
- 收尾面板不再把"没配模型上游"写成警告。试用模式下那是正常状态而非出错，
  改成一行可选的下一步
- `--mode selfhost` 仍会询问登录方式（SMTP 或 GitHub/Google OAuth）——没有它
  谁也注册不了第一个账号，`start` 本来就会拒绝运行
