# AI Store 0.4.0

这一版三件事：**上线第 16 格「数字人直播」**、**三格编码工作台换成同一个外壳**、
**桌面版打开先看见货架，算力可以留在自己机器上**。品牌也在这一版换成 AI Store
（aistore.best）。

## 一、数字人直播（新）

一个数字人实时开播：她自己说话、看公屏、当场答观众。**不是先渲染再播**——
去掉了渲染这一步，说什么当场出画面。

- **十二间房**，每间一套形象 · 音色 · 人设，三样绑死不让自由组合（搭配是设计过的，
  自由组合出来的多数不能看）。列表页是封面画廊
- **评论 / 弹幕接进来**：观众发言进 LLM，她当场说出去；输入框下面另有一条公屏列表，
  飘屏飞过去还能回头看
- **直播间控制台**（管理员专用）：话术按直播间名称一键生成，2000 字起步——十来句
  一会儿就循环一遍，观众看得出来
- **播出质量有账可查**：卡顿、缓冲见底、掉速，每一次都记下来并带上客户端版本；
  出事那一刻把播放器手里的三个数一起报上来
- 同播上限 5 间

## 二、三格编码工作台换成同一个外壳

Claude Code、Codex、OpenManus 从自研工作台换到社区的 pi-web-ui，一个外壳接所有
agent（开关 `USE_CLI_WORKSPACE`，关掉回到原来那套）。

- **思考过程、工具卡片、会话搜索与回放**都有了；每格一套皮肤（赛博朋克 / 炫彩 /
  半透明），名字与皮肤烧进首帧，不会先闪一下别人家的品牌
- **终端点进去直接是 CLI 且免登录**——终端与对话是两条 env 路，以前只接通了一条
- 终端里的 `/model` 菜单改成列**在售目录**：原来那张写死的表点哪行都是 404
- OpenManus 的文件终于落在工作区里（它的工作目录写死在容器内，文件面板一直是空的）

## 三、桌面版

- **打开先看见货架**：16 个产品摆在那里，DSH 只是其中一格，不再自动拉起
- **本机运行器**：计划从服务端下发，客户端只负责执行——算力在你自己的机器上，
  账号 / 模型网关 / 计费仍在云端。多容器栈也能本机跑（真跑通了 Dify 的十个容器）
- 修掉 M 系机器上 `docker pull` 直接失败（不是"慢一点"，是拉不下来）

## 四、打开工作台这件事本身

- **跳转前先把首屏资源拉进浏览器缓存**：后端就绪不等于你能用，有的格子首屏要拉
  十几 MB。现在这段等待在我们自己的进度条上，走多少按真实完成数，不是估的
- 等待页那句"通常需要 X"改成**按格子学出来的**，不再是一句写死的值对所有格子说
- codex 那格冷启动 18 秒降到 7 秒：它把 172MB 临时文件（现解出来的助手与两份一样的
  插件克隆）同步上了对象存储，每次开机整份拉回来

## 五、站点

- 品牌与域名换成 **AI Store / aistore.best**；运营方与服务名进配置，页面上不再出现
  旧品牌。旧域继续服务
- 16 个产品分六类，产品菜单与 `/apps` 都按它排；私有部署重新露出
- 项目移交公司：收起「我们的代码开源」与仓库链接（MIT 声明与第三方开源措辞保留）

## 已知取舍

- **上游中继会抖**。Claude 那条线按请求轮询几家后端，带思考的请求被钉到直连通道，
  而那条通道时快时慢——同一个型号同一时刻实测中位 45.7 秒 / 不带思考 2.4 秒。
  群聊类产品（OpenMausBot）已经关掉扩展思考换速度；工作台两格保留思考过程
- 预载只覆盖首屏那十几个资源，第三方前端自己后续按需加载的块盖不到；跳转之后它
  自己的启动（ComfyUI 建图那种）我们在跨域之外，测不到也管不了
- 等待时长提示要同一格攒够 4 次真实打开才开口，之前显示后端的粗略值
- 直播的话术与形象在控制台里配，普通用户只能看不能开播
