# DSH Cloud 0.3.0

云工作台换了一副底盘：常驻节点上的 Kubernetes 后端，用户数据的正本放对象存储。

## 新增

- 第三个工作台后端 `WORK_BACKEND=k8s`：一台常驻节点上的单节点 k3s，镜像在本地，
  Pod 创建到容器起来 1 秒（ECI 同样的东西 34 秒）。`WORK_BACKEND_PRODUCTS=pi=k8s,...`
  可按产品分派到不同后端，回收会遍历所有后端。节点怎么搭、跨 VPC 的 ssh 三层隧道、
  配额与清单见 `deploy/k8s-node/README.md`
- 用户数据正本放 OSS（`K8S_SYNC_OSS_*`）：Pod 起动前从 OSS 拉回，运行中周期推
  home/workspace，回收时全量推——同步器是原生 sidecar，在应用容器退出之后才收到
  TERM，所以数据库目录推上去的是停机后的一致状态。密钥只给同步容器，跑用户智能体
  的应用容器拿不到；附 NAS/节点到 OSS 的迁移脚本
- 新格子 **pi**：pi 编码智能体 + 社区的 pi-web-ui 前端（顶掉 OpenHands）。整个在售
  目录都能选、思考开关可用，提供方走网关的 Responses 面
- **CrewAI** 换成社区的 CrewAI-Studio：表单搭队伍、一键 kickoff，简体中文
- OpenManus、Claude Code、Codex 的自研工作台换成 AgentsDanceCloud 的设计语言
- Agents Team 0.7.13：十个团队模板、文件面板、删群/移出成员、空房间开场示例
- 16 张卡的副标题按各自专长重写
- 动手验收脚本 `scripts/product_use_check.sh`（真发消息/真敲命令，随机算术题）与
  首屏检查 `scripts/visual_check.sh`（状态码优先，可见密码框才算登录墙）

## 修复

- 就绪 = 代登录已把会话注入 nginx，而不是后端应答：Hermes、Dify、Coze 都改探
  `/__dsh_ready` 标记，冷启动不再闪出别人的登录墙
- 起工作台失败现在记日志（原先三处入口把原因吞掉，只剩一句客气话）
- ECI 镜像缓存被打断留下的永远 Creating 的幽灵实例
- 媒体下单响应丢失不再变成第二次扣费
- 终端里退格削掉汉字的一个字节（起终端前 `stty iutf8`）
- OpenManus/CrewAI 本轮消耗永远显示 0；CrewAI-Studio 中文界面下运行中被钉在
  「团队」页；OpenManus 工作区不再长出 crew/
- pi 的网关令牌不再叫 `OPENAI_API_KEY`（那会把它内置的 OpenAI 提供方点亮）

## 已知取舍

- k8s 节点上的隔离是容器级（共享内核），ECI 是每实例一台微 VM；要更强就在节点上
  加 gVisor
- Pod 异常死亡（不是正常回收）会丢最后一次推送之后的改动，间隔默认 5 分钟
- 「個人成品」页对 k8s 后端暂时为空（正本在 OSS，应用机上还没挂）
