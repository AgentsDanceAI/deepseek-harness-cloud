# DSH Cloud 0.3.0

这一版做成两件事：**把全世界最好的 AI 产品装进一个云**，以及**把它们的底盘从
ECI + 每实例一个 EIP 换成 Kubernetes**。

## 一、全世界最好的 AI 产品，装进同一个云

打开浏览器就能用，**没有第二道登录墙**，模型、积分、机时全部由本站统一供给——
不用注册第二个账号，不用自己填 API Key，不用管服务器。这一版把格子补齐到 16 个：

| 方向 | 产品 |
|---|---|
| 编码智能体 | Claude Code、Codex、**pi**（本版新增，顶掉 OpenHands） |
| 智能体搭建 | Dify、Coze Studio（扣子开源版）、AutoGen Studio、LangChain |
| 多智能体协作 | Agents Team（自研）、**CrewAI Studio**（本版换成社区前端）、OpenManus |
| 个人助理 | OpenClaw、Hermes（Nous Research） |
| 创作 | ComfyUI、Open Design、数字人（全双工） |
| 命令行工作台 | DSH（自研） |

本版在产品面上的改动：

- 新增 **pi**：pi 编码智能体 + 社区的 pi-web-ui 前端。整个在售模型目录都能选、
  思考等级可调，提供方走网关的 Responses 面
- **CrewAI** 换成社区的 CrewAI Studio：表单搭队伍、定角色与任务、一键 kickoff，
  简体中文界面
- **OpenManus / Claude Code / Codex** 的自研工作台换成 AgentsDanceCloud 的设计语言
- **Agents Team** 0.7.13：十个团队模板、文件面板、删群与移出成员、空房间开场示例
- 16 张卡的副标题按各自专长重写，一格一个键
- 就绪判据统一成"**代登录已经把会话注入完成**"（Hermes、Dify、Coze）——冷启动时
  再也不会闪出人家自己的登录框
- 两套验收脚本进仓：`product_use_check.sh` 真发消息、真敲命令、看答案对不对；
  `visual_check.sh` 状态码优先、只有可见密码框才算登录墙

## 二、ECI + EIP 迁移到 Kubernetes

此前每个工作台是一台阿里云弹性容器实例，还要**自动申请一个公网 EIP**；现在它们
是一台常驻节点上的 Pod。

| | ECI + EIP | K8s 节点 |
|---|---|---|
| 从创建到容器起来 | 约 25–34 秒（机房调度 + 建 EIP + 挂镜像缓存） | **1 秒**（镜像已在本地） |
| 每个工作台的公网 IP | 各占一个 EIP，按秒计费 | **不再需要**——经隧道走内网 |
| 用户数据 | NAS | 对象存储（OSS）为正本 |

- 第三个后端 `WORK_BACKEND=k8s`（单节点 k3s）。`WORK_BACKEND_PRODUCTS=pi=k8s,…`
  可以按产品分派到不同后端，回收会遍历所有后端——切换期旧后端上的实例不会漏收
- 应用机与节点跨 VPC 时走一条 `ssh -w` 三层隧道；节点搭建、配额、清单与退场步骤
  见 `deploy/k8s-node/README.md`
- **用户数据的正本放 OSS**：Pod 起动前拉回，运行中周期推 home/workspace，回收时
  全量推一次。同步器是原生 sidecar，在应用容器退出之后才收到 TERM，所以数据库
  目录推上去的是停机后的一致状态。密钥只给同步容器，跑用户智能体的应用容器拿不到；
  附 NAS 与节点本地盘到 OSS 的迁移脚本
- 启动等待页的时间提示改为由后端如实报告

## 其它修复

- 起工作台失败现在会记日志（此前三处入口把原因吞掉，只留一句客气话）
- ECI 镜像缓存被打断后留下的、永远停在 Creating 的幽灵实例
- 媒体下单响应丢失不再变成第二次扣费
- 终端里退格会削掉汉字一个字节（起终端前 `stty iutf8`）
- OpenManus / CrewAI 的"本轮消耗"永远显示 0；CrewAI Studio 中文界面下运行中被钉在
  「团队」页；OpenManus 工作区不再长出 crew/
- pi 的网关令牌不再叫 `OPENAI_API_KEY`——那会点亮它内置的 OpenAI 提供方

## 已知取舍

- K8s 节点上的隔离是容器级（共享内核），ECI 是每实例一台微 VM；要更强的隔离可以在
  节点上启用 gVisor
- Pod 异常死亡（不是正常回收）会丢失最后一次推送之后的改动，同步间隔默认 5 分钟
- 「個人成品」页对 K8s 后端暂时为空：正本在 OSS，应用机上还没挂
