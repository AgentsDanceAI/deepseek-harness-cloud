# DSH Cloud 0.2.2

0.2.1 装完之后的实测修复：三处都是照着屏幕上的提示做、却做不通的地方。

## Bug 修复

- fix(cli): 装完面板印出的 `dsh-cloud up/down` 敲下去是 `command not found`。
  根因隐蔽——`npx` 在**运行期间**把自己的 `node_modules/.bin` 塞进 PATH，
  于是"`dsh-cloud` 在 PATH 上"当场为真、进程一退就没了。现在落在 npx / uv
  缓存里的那份不算"装过"，照旧印回 `npx --yes @agentsdanceai/dsh-cloud …`
  （`uvx` 同理）
- fix(web): 云工作台关闭时「云端体验」整个不渲染，等于让人以为产品没这功能。
  改为指向官方站点——导航栏与 iPhone 卡片都给回这个入口

## 优化改进

- 下载页去掉降级说明与「重新构建中」禁用按钮：本部署没有安装包时，
  macOS / Windows 按钮直接指向官方站点下载，提示压成一句
