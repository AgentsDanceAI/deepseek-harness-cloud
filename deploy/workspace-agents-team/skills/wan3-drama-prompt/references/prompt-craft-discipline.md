# 提示词工程纪律（通用手法）

> 本文件收录**通用的提示词工程纪律**，全部已落到 wan3.0 口径（`@图片N` 指代 + 七大公式）。
>
> **纪律边界**：
> - 与 [`wan3-formulas.md`](wan3-formulas.md) 冲突时，**一律以公式文件为准**
> - 本文件是**补充手法**，不是替代公式；效果以实测为准，交付时不要当成硬承诺

---

## 1. 时间线连续纪律（补强 §6 多镜头公式）

多镜头公式给了「第N个镜头[a-b秒]」的外壳，但没规定**每段内部怎么写、段与段怎么接**。补这三条：

1. **每段四要素**：起始状态 + 可见动作 + 镜头拍法 + **结束状态**。
   「结束状态」是最常漏的一项，漏了下一段就没有落脚点，模型只能自己脑补，跨镜跳变基本从这里来。
2. **上段结束状态 = 下段起始状态**。写完通读一遍：如果第 2 段的开头无法从第 1 段的结尾自然接上，说明中间缺了一个动作，补上或合并。
3. **一段一主动作、一主运镜**。同一时间段里同时要求"固定机位 + 360 度环绕 + 推进"，模型会挑一个执行或三个都做半截。

**时间戳三条硬自检**：
- 从 0 秒起、段间不重叠、中间不留空
- 各段时长之和 **= `duration`**（硬要求，对不上会报错或被裁）
- 单段 **≥ 2s**，否则动作来不及展开

**段数卡尺**（按 wan3.0 `duration` 2–30s 换算）：

| duration | 建议镜头段数 | 说明 |
|---|---|---|
| 5s | 1（单镜头） | 只够一个主动作，写「生成单镜头」别切镜 |
| 8–10s | 2–3 | 安全区 |
| 15s | 3–4 | 4 镜是稳定上限 |
| 20–30s | 4 封顶，或拆任务 | 超 4 镜建议拆成多次任务，逐段生成后剪接 |

**节奏骨架**（仅用于原创内容的默认起手；反推已有成片时按真实切点，**不要套平均分段**）：

- **15s**：0–2 钩子（主体/商品/冲突立刻出现）→ 2–5 第一动作或卖点 → 5–9 推进或关系变化 → 9–12 高潮或效果证明 → 12–15 落点与收尾
- **30s**：0–3 钩子与关系建立 → 3–8 第一阶段 → 8–13 升级 → 13–18 变化或换位 → 18–24 高潮 → 24–28 结果 → 28–30 稳定收尾

## 2. 素材职责声明（补强 §5 参考生公式）

参考生公式只给了「@参考对象」，没说**一个素材负责什么、不负责什么**。多素材场景下这是指代命中率的关键。

**四要素 = 素材编号 + 正向职责 + 生效时段 + 禁止迁移项**

wan3.0 写法：

```
@图片1 锁定人物五官、发型与服装，全片生效；画面背景与图中文字不参与生成。
@图片2 锁定商品外形、材质与比例结构，全片生效；商品结构与比例全程保持不变。
@视频1 只参考运镜方式与动作节奏；其中的人物、场景、品牌标识与声音均不迁移。
@音频1 作为音色参考；音色引用在台词句后紧跟「音色参考 @音频1」，不在开头写"提取音色特征"。
```

三条纪律：

- **禁止迁移项必须写成正向句** —— wan3.0 已废弃 `negative_prompt`，不写「不要参考图中的背景」，写「画面背景与图中文字不参与生成」
- 同一素材承担**超过两项职责就拆成两句**，一句只说一件事
- 多次引用时**每次都重复 @** 一次 —— 这与公式 §5「可在不同位置多次 @ 同一对象」一致，是提高命中率的推荐手法

## 3. 排除层的取舍（补强五层 / 六层结构的排除层）

排除层不是越多越好。堆到二三十条时，模型对每一条的注意力都被稀释。

- **只写 3–8 项**，且只写**这条提示词真实会踩的**风险。给生活方式广告加一堆打斗物理约束，纯属浪费额度。
- **先消矛盾，再写限制**。正文里「固定机位」和「环绕运镜」打架时，加十句约束也没用 —— 回去改正文。
- **常见互斥组合**（下笔前扫一遍）：

  | 互斥 A | 互斥 B |
  |---|---|
  | 固定镜头 | 持续环绕 / 持续推进 |
  | 自然纪录质感 | 每秒强转场 |
  | 浅景深近景特写 | 交代全景空间关系 |
  | 一镜到底 | 硬切转场 |
  | 商品正面 logo 全程朝向镜头 | 360 度环绕展示 |

- **优先级排序**（从这个顺序里挑最相关的 3–8 条）：身份 / 商品稳定 → 物理正确 → 摄影正确（机位与轴线）→ 文字与品牌 → 声音边界

## 4. 复杂动作的可追踪写法（补强 wan3.0 物理交互弱项）

**只在**打斗、追逐、抛接、液体喷射 / 倾倒、多人换位时追加；普通镜头写清动作即可，别过度工程化。

**五要素 = 谁发起 + 从哪里出发 + 沿什么路径 + 作用于谁 + 最后落在哪里**

镜头必须让动作关系可追踪：

- 发力 / 发射前，先让观众**看见发起者的起势动作**
- 飞行物**从发起者身边出现**，不凭空出现在画面中央
- 目标从**正确来向**受击或防守
- 多人换位用**一个双人广角**交代过程，别在特写里换位
- 物体飞行途中**不越轴、不突然反向**

> 与 SKILL.md 的高危动作流程配合：先走「检测→提醒→方案→用户决定」，用户选"硬跑"时再用五要素把动作写死。
> 五要素能提高动作**可读性**，但改变不了 wan3.0 物理交互穿帮的能力边界 —— 诊断到能力边界仍要明说。

## 5. 参考片反推（把成片还原成提示词）

用户丢一条成片说"照这个做一条 / 复刻这个"时的纪律。

**先看六项**：总时长 / 画幅 / 帧率、真实剪辑切点、每镜首帧与尾帧、人物服装商品场景、动作是否真实存在、口播字幕与环境声。

**输出六条规则**：

1. 用**真实切点**分段，不做平均分段
2. 只描述画面里**能确认**的动作，镜头外的一律不写
3. 区分**硬切**与无缝转场，按公式 §6 写在分镜内容开头
4. **不把推断写成事实**（"他应该是在找钥匙" → 不写）
5. **不为了"更精彩"添加**原片没有的抛接、旋转、特技、对白
6. 用户要加戏时**另建「创意延伸版」**，不覆盖直接反推版

**落到 wan3.0 时的形态选择**：有角色图 / 商品图 → §5 参考生；无素材纯复刻 → §2 进阶 + §6 多镜头；原片可直接作为输入 → 走 §7 视频编辑，比重新描述更省力也更稳。

## 6. 一镜到底的写法细则（补强「生成单镜头」控制词）

「**生成单镜头**」「**一镜到底**」是控制词，但控制词本身没给写法。补这四项：

- **摄影机连续路线**：从 A 点出发 → 经过 B → 绕过前景 C → 停在 D 构图
- **人物连续路线**：与摄影机的相对关系（跟随 / 交错 / 反向）
- **遮挡关系**：中途经过哪些前景遮挡（柱子、门框、走过的人）—— 遮挡是藏接缝的地方
- **速度变化**：哪一段加速、哪一段停住

写一镜到底时，**时间段只代表动作阶段，不代表切镜**，务必在结尾补一句：

```
全片为一个连续镜头，不硬切、不瞬移，机位运动连续。
```

## 7. 视频延长与智能编辑的要素补全（补强公式 §7）

公式 §7 给了骨架，这两项把要素写全：

**视频延长 = 原片末帧状态 + 新增时长 + 衔接动作 + 新增事件 + 结束状态 + 连续性约束**

> 公式要求"只写后续动态"，所以**末帧状态一句话点到即可**（用来对齐衔接点），不要展开重描述整个画面 —— 展开会让模型从头再演一遍。
> 需要换场景时，明确一个**可见转场载体**（推开的门、掠过的车窗、经过的柱子）和前后同方向运动，否则接缝硬。

**智能编辑 = 生效时段 + 定位方式 + 目标对象 + 从 A 变成 B + 保留项 + 声音要求**

> **定位方式**比名词更能锁住目标：「画面左侧的」「人物手中的」「桌面右上角的」
> **保留项**就是「其他保持不变」，但**点名要保的东西更稳**：「保持人物面部、动作、构图、背景光线与机位运动不变」
> **声音要求**：保留原声 / 去掉原声；改台词时必写「保持人物音色和语气」

## 8. 白膜转成片的粗细分类（补强公式 §5 白膜参考）

公式只给了一句写法，按素材精度分两类补细则：

**粗白膜**（只有几何体，用来定动作骨架、站位与运镜）——
必须写清**每个几何模型对应哪个角色或道具**的映射，以及四肢 / 翅膀 / 尾巴等完整动作链：

```
将 3D 预览视频转化为正式成片，预览视频中左侧的白模人形换成 @图片1 的男人，
右侧的白模人形换成 @图片2 的女人，中央的白色方块换成一张深色木质餐桌，
保持原有运镜、走位与两人相对距离，两人四肢动作与预览视频逐帧对应。
```

**细白膜**（已有完整模型，只做材质光影渲染）——
写渲染目标 + 分时段材质光影 + 场景 + 特效 + 全局一致性，并**显式声明辅助元素不进成片**：

```
成片中不出现轨迹线、坐标轴、相机锥体、网格地面与视窗界面元素，画面为完整实拍质感。
```

> 白膜的价值在于**运镜与走位已经确定**，提示词重点是"换成谁、换成什么材质"，不是重新设计镜头。

## 9. 最低质量线（交付前逐条自查）

- 前 **1–2 秒**必须出现主体 / 商品 / 冲突 / 强视觉动作，钩子别放到第 5 秒
- 人物、商品、场景**前后一致**
- 时间轴从 0 覆盖到结尾，**各段之和 = `duration`**
- 每段动作在分配时间内**做得完**（5s ≈ 1 个主动作；台词字数 ≈ 时长 × 4 字）
- 有 BGM 时写清类型 / 速度 / 乐器 / 情绪曲线 / 结尾方式，且与关键动作有节拍对应；不要 BGM 按控制词写「**无背景音乐**」
- 结尾有**明确落点**：动作落点，或稳定的英雄画面（商品正面定格 / 人物定格表情）

> ⚠️ BGM 的**标准公式只有「配乐 + 风格」两段**（见 [`wan3-formulas.md`](wan3-formulas.md) §4）。
> 上面的"速度 / 乐器 / 情绪曲线 / 关键节拍点"属于**扩展写法**，卡点精度以实测为准 —— 对客户不要承诺 wan3.0 能精确卡点。
