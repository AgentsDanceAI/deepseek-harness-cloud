# 剧情 GoodCase 范例库（短剧 / 剧情向）

本文件只收**短剧 / 剧情 / 影视 / MV / 动画 / 游戏CG / 纪录片**类范例。
用法：这些是**已验证能出好片的写法样板**，写新 case 时优先照这里的结构套，比自己从零编更稳。与 `wan3-formulas.md` 冲突时以公式文件为准，本文件是"公式的剧情落地样板"。

> wan3.0 剧情向优势定位：**影视创作**主打 30 秒时长、真实场景还原、多角色精准一致性、AI 短剧 / 短漫剧 / 音乐舞蹈 MV / 生活 Vlog；**文旅传播**主打真实场景还原（自然风光/人文景观/地方美食/城市形象片）。

## A. 30秒一镜到底 · 单镜头长叙事（核心强项，★ 短剧首选）

Wan3.0 的杀手锏是原生 30 秒时长 + 单镜头连贯运镜。**只要能一镜表达完，就不要拆分镜**——拆了反而丢连续性。

### A1. 情绪特写 · 中近景 · 一句独白（最基础打法）
**结构**：主体外观 + 场景氛围 + 说话内容 + 情绪 + 光线 + 镜头呼吸感。
```
这是一个正面的近景镜头，画面主要呈现<主体外观：年龄/发色/服饰/上半身>。镜头稍微偏一点点，
可以看到左边还有一个人，但背景被虚化处理了，看起来很模糊。
<主体>正对着镜头说话，嘴巴在动，<眉头/眼神/表情氛围>。
光线从<方位>照下来，把<主体>脸上的轮廓衬托得很自然，甚至能看到<皮肤/服装>真实的质感。
镜头虽然固定，但带着一点点人手持拍摄时的轻微呼吸感和晃动，视线从<起始动作>慢慢变成了<结束动作>。
```
**为什么好**：不写台词内容也能出片——用"嘴巴在动+眉头皱着"锁情绪，用"手持呼吸感+视线变化"给动态。适合毕业演讲、忏悔独白、诀别对话等纯情绪戏。

### A2. 悬疑长镜头 · 空间穿越 + 追踪 + 台词爆发
**结构**：色调滤镜 → 场景空无一人氛围 → 镜头起点 → 主体冲入 → 沿动线跟随 → 高潮呼喊。
```
一段<现代悬疑>风格的电影感长镜头，整个画面呈现出<强烈的淡绿色滤镜风格>，
营造出一种<基于淡绿色系的清冷氛围>。在<散发着冰冷白光的荧光灯下>，
<空无一人的医院走廊>呈现出低饱和的色彩与极高对比的光影关系，锐利且非人情化。
镜头从<护士台后方>开始，<一名身穿墨绿色夹克的女子>猛地从<走廊尽头的门后>冲入，
沿着对称的中心线向镜头快速跑来，摄影机流畅地向后移动。
她的<脚步声急促而响亮，口中焦急地呼喊>。
最终，她冲到台前，双手用力拍在台面上，绝望地环顾四周，
发出几近崩溃的求助呐喊，声音在只有微弱设备嗡鸣的寂静中回荡。
```
**为什么好**：色温滤镜锁氛围（"淡绿色系"贯穿），摄影机运动写成"向后移动"避免"跟拍/环绕"歧义，声音层显式写"脚步声+呼喊+设备嗡鸣的寂静"三层。

### A3. 多角色连续快摇（一镜到底交替对白，★ 高难度）
**结构**：全程"镜头快速左摇/右摇 + 不要切镜"锁住一镜到底，逐句在两个角色之间来回甩头。
```
镜头1 [0秒-30秒]，近景，平视视角，连续快速摇镜，一镜到底（单镜头连续无缝运镜）：
镜头手持拍摄一镜到底，近景，
镜头一开始，拍摄<角色A>，<角色A表情>，<方位描述>，对<角色B>下达指令，说道："<台词1>"。
说完后镜头快速右摇到<角色B>面部近景，镜头不要切镜，<角色B>面部朝向画面<方位>，
<角色B情绪>，他嘴唇微动，<神情描述>，向对方阐述到"<台词2>"，
说话时，头部伴有极其轻微的自然晃动，说完后镜头快速左摇到<角色A>面部近景，镜头不要切镜，
<角色A>思索了一下，一边<小动作>，向<角色B>说到"<台词3>"，
<角色A>说完台词后，镜头迅速右摇到<角色B>面部近景，不要切镜，……
```
**关键词**：**"一镜到底/连续无缝运镜/镜头不要切镜"** 反复出现，配合"快速左/右摇"给方向。每次交换加一句表情/微动作描述强化角色状态延续性。适合审讯戏、导演调教演员、情绪反转喜剧。

### A4. 硬核奇幻 / 战争 · 分段时间线 + 明确剧情节拍
**结构**：0—X秒 / X—Y秒 段落式描述，每段独立小标题（"死亡之后仍在战斗"/"废城自动战争"/"花朵出现"），每段独立视觉重点 + 摄影机指令。
```
生成一支 30 秒、16:9 横屏比例的<成人科幻战争动画>短片。
画面采用：<CGI/生物机械/骨骼纹理/…列出美学词典>
30 秒剧情与动态时间轴
0—4 秒｜<小标题>
    <镜头起点+主体动作>
    <摄影机运动>
    <环境细节>
4—8 秒｜<小标题>
    <镜头连续/切换指令>
    <多重景别切换 or FPS 穿越轨迹>
……
运镜设计
    <微距开场/贴地追踪/内部穿越/爆炸镜头震动/环绕/低空FPV/大远景收尾>
动态重点
    <关节要有重量/断裂后仍符合机械结构/柔软与硬质反差/背景不能只是爆炸>
```
**为什么好**：段落时间线拒绝"抽象一句话"，每段独立情绪+视觉锚点，末尾"运镜设计+动态重点"两个专用段落把导演意图从叙事段抽离，避免相互稀释。

### A5. 灾难 / 特效大片 · 分镜制式 + 音乐段
**结构**：分镜1—N 每镜一句话概括 + 主体+镜头+光影+核心视觉冲击；末尾单独一段写配乐。
```
这是一段<30秒电影级>灾难<怪兽登场>场景，整体氛围参考<好莱坞灾难怪兽大片>。
故事从<起点>开始，镜头先建立<氛围>，再逐步通过<细节>制造压迫感，
最终<高潮事件>。整体要求写实、厚重、真实比例、强烈<水体/火焰/风暴>冲击。
分镜1：<环境全景+主体>+<氛围形容>
分镜2：<中近景聚焦+光影动作>
分镜3：<主体视角+悬疑感>
……
分镜10：<终极定格>
配乐采用<好莱坞灾难怪兽电影风格>。开场以<低沉环境音/低频轰鸣/稀疏鼓点>营造<不安感>；
随着<事件递进>加入<铜管/重型打击乐/低频冲击>；
巨兽破浪而出时，爆发出<灾难级高潮>；结尾以<末日感长音>收束。
```
**为什么好**：配乐段独立写清"开场→递进→高潮→收束"四段动态，比"史诗配乐"这类模糊词有效得多。

### A6. 荒诞冷幽默 · 静观旁白式（反差喜剧）
**结构**：明确注明"运镜风格是冷静的旁观与荒诞的特写"→ 用静态中景+突发极端特写制造笑点。
```
运镜风格是"冷静的旁观与荒诞的特写（Calm Observation & Absurd Close-up）"：
大量使用固定的中景镜头和缓慢的横移，以一种非常冷静、客观的视角来记录事件，不做任何情绪引导。
在关键的荒诞行为发生时，镜头会突然给到一个极端的特写，
比如<触发瞬间>，或者<反应镜头面部表情>，通过这种突兀的放大来制造笑点。
```
**为什么好**：镜头语言直接命名 + 括号英文补充，比"喜剧感"这种词有效。反差喜剧必须显式写"静观 vs 特写"两种镜头切换。

### A7. 2D 日式 / 手绘动画（风格化叙事）
**结构**：明确画风+调色+镜头运动+人物设计+情绪节拍。
```
这是一段精致的日式2D卡通动画短片，对情绪高潮场景需要有细腻处理，
尤其是<天空色彩渐变与云层光影>的运用。需要有<戏剧化的逆光效果>，
在空间感上采用带<强烈透视纵深>的构图，强调人物在辽阔场景中的<渺小与坚定>。
<场景>：<地点+氛围+天空色彩渐变从X到Y+风吹卷起地面细节>。
主角设计：<性别年龄+外观+服装破损细节+眼神情绪>。
镜头以<起始景别>开场，<主角在场景中的比例感>，镜头缓慢推进至<下一景别>，
<裙摆/发丝物理反应>。她<情绪转折>，脸部特写捕捉<她眼中的复杂情绪>——<情绪1>、<情绪2>，最终<情绪3>。
她<决定性动作>，镜头切换为<高速环绕>，<背景色彩变化>，
最终她<核心动作瞬间>时画面进入慢镜头处理，<视觉高潮细节>。
```

### A8. 3D 暗黑奇幻 · 反派独白（配音 + 特效）
**结构**：单镜头微俯视 → 磁性英文台词 → 手掌特写做特效 → 定格残忍笑容。
```
3D动画短片，30秒，<题材>，单镜头，<场景>。
<外观：面部+发型+眼睛+皮肤+饰品+服装>。
场景：<光线+粒子+背景模糊人影>。
镜头：<景别+俯视/仰视>，浅景深锁定<主体>，随独白极缓速上摇至平视。
动作：<主体>斜侧而立，垂头轻蔑一笑，侧视手掌后转向镜头，
抬头以<音色形容词>声线道："<英文台词>" 
<手部特写：能量凝聚/爆裂/消散> 说到："<第二句台词>"，
猛然攥拳，<特效详细描述>，最终露出<终结表情>。
配合<音效名称>与<能量音效>，<语种/情绪>贯穿全程。
```
**为什么好**：英文台词直接写引号，配音会照读；音色形容词（"阴冷磁性"）比"男声"精准；特效分三阶（凝聚→爆裂→消散）避免特效瞬间闪过。

## B. 多镜头分镜（`第N个镜头[a-b秒] xxx`）

多镜头公式（§6）需要 **总体描述 + 镜头序号 + 时间戳 + 分镜内容**。时间戳段数和须等于 duration，前后连续无跳空。

### B1. 六镜头首帧参考 · 情感短剧（★ 分镜标杆）
```
参考 @图片1 的分镜图，
镜头1：<环境全景，主体在何处，气氛细节，远处什么隐没>；
镜头2：<中景，两个主体的相对位置，天气/物件延伸>；
镜头3：<透过何物拍谁的特写，情绪细节，轻声说{台词内容}>；
镜头4：<从谁的背后越肩拍向谁，远处什么亮着灯，光晕>；
镜头5：<双手/物件特写，谁递给谁什么，颤抖细节>；
镜头6：<主体独自站在哪，目送方向，另一主体已不在，环境收束>
```
**核心手法**：
- 台词写在花括号 `{}` 里且**只写在一个镜头**——避免多镜头同一句台词重复；
- 越肩镜头写"从A背后越肩拍向B方向"给相对方位；
- 情绪不写"悲伤"而写"眼眶泛红"，用外化动作代替情绪词。

### B2. 5 张关键帧 + 翻牌切换 · 10秒短片（多主体展示型）
角色亮相 / 人物变装类内容，用 **"每人 2 秒 + 统一切换方式 + 位置始终中心对齐"** 三把锁：每个主体停留时长一致、切换手法全片统一（翻牌/淡入淡出/推移三选一）、主体始终中心对齐不漂移。

## C. 复杂动作 / 物理表演（本 skill 高阶专项）

### C1. 极限速度感 · "定点悬停—瞬间弹射—完全急停—锐角变轨"（★ 高难度物理运动）
**结构**：先命名运动方式（"蜻蜓式"），全片计数硬约束（"至少出现六次爆发移动"），每次弹射三要素（帧数+跨越比例+2-4帧完全定格）。
```
最高优先级要求：<主体>必须采用<蜻蜓式"定点悬停—瞬间弹射—完全急停—锐角变轨">的运动方式。
禁止将其表现为<普通仙女缓慢漂浮、匀速前进或连续平滑滑翔>。
全片前 X 秒至少出现 N 次清晰可辨的爆发移动。
每次弹射必须在 3—5 帧内跨越画面宽度的 60%—90%，到达新位置后立即完全停止 2—4 帧。
冲刺过程只留下 1—2 帧粉色身体残影和透明翅膀拖影，急停后的角色必须瞬间恢复锐利。

角色造型：<单一角色 + 外观 + 翅膀数量/结构 + 姿态说明——悬停时X姿态，爆发前1-2帧转Y姿态，急停时Z姿态>
场景：<真实空间+具体道具颜色枚举+空间过渡到另一空间>
摄影机规则：<每次弹射逻辑：暂锁定→冲出画面2-4帧→摄影机慢0.1-0.2秒才追→短暂越过→反向微调→重新发现>
运动画面要求：<每次冲刺至少三种速度证据同时出现：位置改变+大小改变+前景掠过+拖影+摄影机延迟>
禁止条款：<禁止只用翅膀振动表现速度；禁止真正消失/传送；禁止摄影机固定在角色背后>
```
**为什么好**：把"高速"分解成**可验证的物理证据**（帧数、跨越比例、大小变化），彻底避免模型偷懒用运动模糊糊弄。适合追逐戏、格斗爆发、超能力瞬移。

### C2. 精致对称美学 · 定格与追踪（超现实动作幻想）
```
0-4秒（全景/对称定格）：
画面：<空间描述+左右对称>。<主体1> @图片1 <动作姿态腾空>。
<主体2> @图片2 <相对方位+夸张扭头动作>。
细节：两者的动作被凝固在一种"动态的静止"中，如同精致的发条玩具。
背景中的<拱门/壁灯/地毯花纹>全部严格左右对称。

4-9秒（侧跟拍/剖面视角）：
画面：<视角切换>。<主体1>在前景从左向右匀速跑过，<步伐机械而优雅>；
<主体2>在中景从右向左反向穿过，形成<交叉动线>。
风格：<背景层次+色彩+严格垂直水平>。

9-13秒 [空间转场/特写]：
画面：<正面平视特写>，聚焦于<核心物件>。
<主体们>被困在<环境>内，随<物理规则>翻滚。
细节：<主体>并未惊慌，而是保持着<僵硬的姿态>，眼神空洞地直视前方。
```
**为什么好**：对称美学显式写"严格左右对称"+"没有任何倾斜"，比"Wes Anderson 风格"这种品牌词更可控。

### C3. 武侠打戏 · 一镜到底 + 招式流程 + 音效纪律
```
1️⃣模块一·多模态参考层
基于上传的角色卡，严格保持<男角>的<发型+瞳色+面部轮廓>特征一致；
严格保持其<外套/内衬/腰带/饰品>造型细节一致。
基于上传的角色卡，严格保持<女角>的<发型+侧脸+瞳色>一致；严格保持其<劲装+皮带+衣领>一致。
场景严格基于上传的<湖畔芦苇滩图>，不替换、不混入其他场景元素。

2️⃣模块二·全局设定
基础环境与质感：<环境细节+可借力物+空气中粒子>
视觉风格：<写实武侠质感+电影引用如"一代宗师逆光""卧虎藏龙旷野">+光影切割
镜头语言：<开场固定中近景→打斗多机位快切→速度渐变（正常→短慢镜→弹回）→次数限制"慢镜≤2次单次≤1秒"→切镜频率提升但轴线连续→收尾拉升全景>
表演核心：<对白简练锋利+招招凌厉+每一击有发力/受力反馈+杜绝空转>
台词与音效纪律：<全片保留同步对白+不用字幕+对白仅极短两句+打斗全程仅呼吸+拳风+布料摩擦+落地闷响+不使用配乐+环境音强度随打斗攀升+收尾极简重音>
禁止项：<屏幕字幕/BGM喧宾夺主/穿模/断肢/浮空/慢镜超限/轴线错乱/仪式动作/静止超1.5秒>
空间调度：<三个空间锚点：芦苇丛边界/岩石群/湖岸→动线：静→动→缠斗→高潮摔投→定格>

3️⃣模块三·时间戳戏剧分镜
【0-1.5秒】<起势+固定中近景+一句挑衅>
【1.5-3秒】<回应+一句应战+打斗引爆>
【3-4.5秒】<第一次交手+手持贴身跟拍+微震>
【4.5-6秒】<反手借力+方位切换>
……
```
**为什么好**：模块化写法（多模态参考层 / 全局设定 / 时间戳分镜）把角色一致性、镜头纪律、时间戳三件事分开锁定，互不干扰。武侠戏最容易崩的"慢镜滥用/静止过长/穿模"都在禁止项里单独点名。

## D. 风格化情感叙事（日常戏 · MV · 文旅）

### D1. 温暖情感短片 · 拉面店 / 独居动物（生活流）
**结构**：地点氛围 → 主体日常动作 → 情感锚点物件 → 收尾定格。全片无高潮，靠场景颗粒度取胜。**慢节奏戏用"细节堆叠"而不是"事件推进"**。

### D2. 音乐 MV · 分镜制 + 音乐节奏词
```
一段<9秒>MV短片，画面<饱和度/胶片颗粒/年代感>，主唱<外观+情绪>。
0-3s <定场镜头+主唱位置+乐器/舞群分布+镜头开场>
3-6s <节奏切入+镜头开始跟随节拍+主体动作变化+光效变化>
6-9s <副歌高潮+舞群同步动作+镜头快速环绕+光线闪烁+定格>
配乐：<风格+BPM+主要乐器+高潮出现在Xs>
```
**关键词**：**BPM 或节奏点显式写出**，让模型知道音乐在哪里爆发。

### D3. 文旅品牌片 · 无对白纯环境音
**结构**：真实场景还原能力 → 拒绝人物剧情 → 大量空镜 + 缓推 + 环境音 + 收尾字牌。
```
无对白，纯环境音（<风/水/鸟鸣/远处人声>），
镜头1：<全景空镜+缓推>，
镜头2：<局部特写+材质呼吸感>，
镜头N：<定格画面+字牌"XXX"淡入>
```

### D4. 敦煌 / 中式古风 · 华服展示（融合主体展示与叙事）
**结构**：单人物 + 每 2 秒微动作 + 环境静止 + 头饰/服饰细节独立特写。结构同 B2 翻牌三把锁，古风类可延长到 15 秒并加轻柔环境音。

## E. 动画 / 游戏 CG / MG 视觉

### E1. 3D 动画奇幻 · 探险少年 + 巨大生物显现
**结构**：4 镜头明确编号 + 每镜时长 + 硬切转场关键词 + 音频类型独立段。
```
一段共4个镜头场景的3D动画奇幻短片，从<谨慎接近>到<巨大生物显现>再到<震撼凝视>，
情感表达为<安静、神秘、惊叹>。场景环境为<夜色森林中的浅湖>，
室外自然空间，湖面平静，周围高树包围，漂浮发光花瓣分布于水面，空气里有淡薄雾气。
主色调为<青蓝、墨绿、月白>，冷色调为主，局部发光植物提供<青白色高亮>，
饱和度中等，对比度中高。
主体为<探险少年与湖中心巨大透明植物>。
镜头一为<中远景定场>，<主体从画面X侧踩着Y向Z移动>，镜头缓慢前推；
镜头二<硬切到背后中景>，<跟踪+涟漪+花瓣>；
镜头三<切到湖心中景>，<主体升起+材质+光影>；
镜头四<切到侧面中近景>，<表情变化+视线凝视>。
音频类型包含环境音与音乐，无语音内容，仅有<夜间虫鸣、轻微水声、植物上升时的低频共鸣和空灵合成器与弦乐>。
```
**为什么好**：情感表达单独一句概括"从X到Y到Z"，模型知道情绪弧线。音频类型段用**排除法**（"无语音内容"）显式关闭台词。

### E2. MG 光球追逐（抽象元素）
**结构**：把 MG 元素当成角色写——赋予速度、体积、光晕、拖尾、碰撞反应。禁止"抽象光球飞来飞去"，改成"直径N厘米的青色光球以每秒M米速度沿地面弹跳，尾迹长X"。

### E3. 游戏 PV / 战斗爆发
参考 A4 硬核奇幻 + A5 灾难分镜双结构：一镜到底段落式时间线做核心动作，末尾单独"配乐+音效"段。

### E4. 手绘 / 油画笔触（85字级极简）
```
手绘风格动画，油画笔触，色调偏冷，<地点场景>，
<主体1从远处出现>，<核心动作>，<次要主体反应>。
```
**为什么好**：Wan3.0 对短提示词也能出片，风格化短片用极简写法反而更自然。**≤100 字的极简写法用于风格化时最有效**，不要过度堆砌。

## F. 长时段 Vlog / 角色纪录片

### F1. 拟人化动物日记 · 一天 24 小时（10 段以上分镜）
**结构**：每 3-5 秒一段，覆盖主体全天节奏（清晨-白天-傍晚-夜晚），每段一句话动作 + 一句话情绪 + 一句话环境。**主体外观锁在参考图**，提示词只写动作和场景变化。
```
参考 @图片1 的<主体>形象，纪录一天：
镜头1 [0-3s] 清晨阳光洒在<窗边>，<主体动作+情绪>
镜头2 [3-6s] <主体到达吃饭的地方>，<吃相细节>
镜头3 [6-9s] <外出场景>，<相对环境比例>
……
镜头N [X-30s] <夜晚回家>，<终结姿态+光线收束>
```
**为什么好**：把 30 秒长时段拆成 8-10 段，每段独立时间戳，用参考图锁外观避免每段重复描述外观。

## G. 视频编辑 V2V（剧情向）

V2V 公式与四类玩法见 [`wan3-formulas.md`](wan3-formulas.md) §7，剧情向最常用的四种写法：

### G1. 保留音色改台词（★ 短剧续集常用）
```
保持人物<音色和语气>，将<女生>的说话内容改为："<新台词>"
```
**关键**：显式写"保持音色和语气"，否则模型会重新生成音色。

### G2. 换背景 / 换天气 / 换风格 · 其他保持不变
```
把视频<修改为阴天> / <改为暖色调> / <改为2D卡通风格>。其他保持不变
```
**关键**：结尾必写"其他保持不变"，防止连带修改人物/动作。

### G3. 时序编辑 · 动作接续
```
让视频里的<男人>拿起<水杯>，喝下一口水
```
**关键**：只描述新增动作，不复述已有内容。

### G4. 白膜转成片
```
将3D预览视频转化为正式成片，把预览视频中<白模角色A>换成<@图片1 的角色>，<白模角色B>换成<@图片2 的角色>。
```

## H. 首尾帧 · 图生视频（提示词 = 运动 + 运镜）

首尾帧图像已经锁定主体/场景/风格/构图，提示词**只写动态过程和运镜**，禁止复述外观。

### H1. 首帧图生（最短写法）
```
<主体动作过程描述，可加副词控制速率>。<运镜指令>
```
示例：
```
女子缓慢地转身走向窗边，撩起窗帘一角。固定机位
```
```
少年快速奔跑冲向镜头，落叶被踩飞。镜头轻微向后拉远
```

### H2. 首尾帧模式
首帧+尾帧两张图确定起点与终点，提示词描述中间过渡。**明确说"从首帧过渡到尾帧"** 是可选的，但建议在过渡不明显时补上。
```
<起始状态：来自首帧> → <过渡动作/时间流逝/相机运动> → <结束状态：来自尾帧>
运镜：<固定/推进/环绕/拉远>
```

### H3. 首尾帧防呆铁律
- 禁止在提示词里写"角色穿着红衣"这类首帧已确定的外观（会引起冲突）；
- 时间流逝类过渡（"经过一夜"/"季节变化"）需要显式写，模型不会自己脑补；
- "固定机位"需要显式写，否则默认会有轻微运镜。

## I. 参考文件 / 网页深度思考模式（长文本剧本转成片）

Wan3.0 支持 file/link 深度思考（≤50 页/1 个文件或网页）。**只提交文件不给提示词也能出片**，但建议补一句意图。
```
参考文件<剧本.docx>，生成<核心场景>的<时长>视频，突出<情绪/画质>。
```
**限额**：文件+网页二选一 ≤1 个 ≤50 页，prompt ≤5000 字符（见 `wan3-protocol.md` §2），含视频输入时输入+输出 ≤30 秒。

## J. 6条通用增益（剧情向）

### J1. 情绪不写"悲伤"，写外化动作
把"她很悲伤"改成"她眼眶泛红/嘴唇微微颤抖/手指用力攥紧衣角"。模型对**可视化的物理动作**响应远好于抽象情绪词。

### J2. 台词只写一次，写在花括号里
`{到了那边记得发消息}` 只出现在一个镜头。避免多镜头同一句台词，否则模型会来回念。多角色对话时每人各写一句 + 明确谁在说。

### J3. "一镜到底"必须显式写
默认多镜头会切分。要一镜就要写 **"一镜到底/连续无缝运镜/镜头不要切镜"** 三个关键词至少出现一次，快摇/横移期间反复强调"镜头不要切镜"。

### J4. 慢镜数量与时长必须限死
"打戏用慢镜"极易被模型滥用。写清 **"慢镜/定格次数不超过 N 次，单次不超过 X 秒"**，收尾定格是否算慢镜也一并写清。

### J5. 台词与音效纪律独立成段
不要把"打斗全程无对白"塞进打斗描述里，要独立成一段"台词与音效纪律"：
- 是否有对白（哪几个镜头有）
- 有无字幕（默认无）
- 是否有配乐（否则写"不使用配乐/无背景音乐"）
- 环境音清单（枚举 3-5 类）
- 音效强度变化曲线（"随情绪攀升/骤然收束"）

### J6. 空间调度显式命名锚点
多镜头戏容易站位漂移。用"空间调度"独立段落写：
```
空间调度：以<锚点A>、<锚点B>、<锚点C>三个空间锚点构建动线——<A→B→C 的动线描述>
```
每次转场前后主体相对锚点的位置必须能对得上。
