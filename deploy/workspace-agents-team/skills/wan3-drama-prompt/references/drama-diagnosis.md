# 短剧 BadCase 诊断手册（wan3.0-video）

诊断只做三件事：**复述现象 → 归因到四类之一 → 给最小补丁**。
不许在没看清现象时就开补丁；不许一次改五处以上；不许把补丁写成新一版完整提示词。

## 零、先做一致性体检（占 BadCase 大半）

拿到老 prompt，先花 30 秒过这七项，命中就直接改，不用等归因：

| 体检项 | 命中特征 | 处置 |
|---|---|---|
| 残留否定句 | 出现「不要 / 避免 / 禁止 / 不能」 | `negative_prompt` 已废弃，全部转**正向排除**（"不要抖" → "机位与焦距全程不变"） |
| 老指代写法 | 出现「图1 / 图2 / 视频1」 | wan3.0 口径是 `@图片1` / `@视频1` / `@音频1`，**带 @、用全称**；顺手核对序号与 `input.media` 顺序 |
| 声音层为空 | 全篇没有一句声音描述 | `audio` 默认 true，模型会自己配旁白与 BGM → 补「全片无台词，无背景音乐，仅保留 XX 环境音」 |
| 分镜没声明 | 想要一镜到底但没写 | 补「**生成单镜头**」或「**一镜到底**」；要多镜就按「第N个镜头[a-b秒]」写全 |
| 比例写在文字里 | 提示词里写"竖屏 / 9:16" | 模型不吃，改传参数 `ratio=9:16` |
| 时间戳不连续 / 求和 ≠ 时长 | 多镜头各段时间戳有断档、重叠，或相加不等于 `duration` | 改成首尾相接且求和 = `duration`；每段补"结束状态"，上段结束 = 下段起始（`prompt-craft-discipline.md` §1） |
| 正文自相矛盾 | 既写「固定镜头」又写「推轨跟拍」、既要「站位全程不变」又要「两人换位」 | 互斥项只能留一个，对照 `prompt-craft-discipline.md` §3 互斥组合表 |
| 道具/法器用相对方位描述 | 出现「（图片右侧为剑柄）/（图左边是枪管）/（参考图上端为发光端）」 | wan3.0 对参考图左右/上下**镜像不稳**，相对方位会漂移 → 全部改成**功能命名**（手柄/剑柄/发光端/尾端/眼球端），并显式声明"角色**双手握住手柄部分**"（不写"握住图片右侧"） |

## 归因四分类

| 类 | 含义 | 处理方向 |
|---|---|---|
| **A 提示词写法** | 缺句、写了否定、外观复述抢注意力、空间没写死、情绪写成静态形容词、指代写法不对 | 改句子，成本最低 |
| **B 形态选错** | 该用全能参考却用了 T2V；该用首尾帧却硬写转场；首尾帧模式还想 @图片N；该走 V2V 却重新生成 | 换 `media` 组合，重跑 |
| **C 参数不匹配** | duration 与台词字数/镜头数不匹配、ratio 没锁、audio 忘关、忘开 thinking、输入总时长超 30s | 改 `parameters`，提示词基本不动 |
| **D 模型能力边界** | 剧烈物理交互穿帮、特效动效弱、空间逻辑已知错误 | **明说提示词解决不了**，给换形态/拆段的替代路径 |

归到 D 时必须直说，不要用一堆无针对性的"高质量、电影级、8K"堆砌词假装修好了。

## A 组｜角色一致性症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 角色中途换脸 / 变成另一个人 | A 或 B | 补：结尾加「人物五官与服装全程保持一致」；若原本是 T2V → 改走全能参考挂角色图（B） |
| 多角色互相"串脸"，A 长成 B | A | 补：结尾加「N 人五官与服装各自保持稳定不互相混淆」；同时检查是否让多人同时做主动作，只留一人主动作 |
| 指代错了人（说 @图片1 却动了 @图片2） | A | 查 `input.media` 数组顺序 → 修正提示词里的编号；**图片与视频分开计数**（第一张图 = @图片1，第一个视频 = @视频1） |
| 指代整个失灵，模型像没看见参考图 | A | 检查是否用了老写法「图1」→ 改成 `@图片1`；动作句里**重复 @ 一次**（推荐手法） |
| 服装细节漂移（颜色/领口变了） | A | 删掉提示词里对服装的复述句（参考图已承载），补「服装保持一致」 |
| 中途自行切镜导致角色瞬变 | A | 补：句尾加「生成单镜头」或「一镜到底」 |
| 用了 `reference_video` 后角色反而更不稳 | C | 检查"输入总时长 + 输出 duration ≤ 30s"；超了会被裁；改短 duration 或减输入视频 |

## B 组｜台词与口型症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 台词只念了一半就截断 | C | 字数超 duration×4 → 加 duration，或删句拆段（拆段做法见 templates §3） |
| 口型与台词完全对不上 | A | 确认台词用了**中文引号内嵌**格式 `@图片1 说："…"`；补「口型与台词同步」 |
| 念出了提示词里的描述文字（把"情绪压抑"念出来） | A | 六要素描述必须在引号**外面**；把引号内多余内容清出去 |
| 语气飘 / 每次念法都不一样 | A | **人声六要素缺项**：内容 + 情绪 + 语调 + 语速 + 音色 + 口音，缺哪项模型就在哪项自由发挥，补齐 |
| 音色不是想要的 / 多角色音色混了 | B | 参数侧给每个角色挂 `reference_voice`（挂在对应 `reference_image`/`reference_video` 子对象上）；提示词侧在台词句后再补「音色参考 @音频1」，两者可叠加 |
| 写了音频参考但音色完全没生效 | A | 用了独立成句的前置提取式（"提取 @音频1 中的音色特征，并让 XX 说…"）→ 改为**与说话动作同句的台词后缀式**：「XX 说出台词："……"，音色参考 @音频1」 |
| 明明不要人声却出现旁白 | A + C | `audio` 默认 true → 补控制词「**全片无台词**」，仅保留环境音；或直接 `audio=false` |
| 自己配了 BGM | A | 补控制词「**无背景音乐**」 |
| 音效很敷衍 / 跟画面对不上 | A | 音效按三段公式写：**音源材质 + 行为 + 环境音**（"一个玻璃小球从桌面掉在木质地面上，发出'砰'的声音，室内安静环境"） |
| 拆段后两段情绪/口型断裂 | A | 下段首句加衔接锚点（复述上段结尾半句的语气或动作起点），并取上段末帧作下段 `first_frame`；或改走 V2V 视频延长直接续 |

## C 组｜表演与情绪症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 演员呆脸，没有情绪 | A | 情绪写成了静态形容词 → 改成**变化过程**：「眉头由平缓逐渐皱紧」「眼神从躲避转为直视」 |
| 表情乱跳 / 一秒一个情绪 | A | 情绪转折过多 → 删到只留 1 个转折（5s 一个、10s 最多两个） |
| 动作幅度太小，几乎静止 | A | 补幅度与速率：「向前迈半步」「抬手至肩高」「以正常步速」（进阶公式要求运动写**幅度+速率+作用效果**） |
| 动作太快像加速播放 | A | 补「动作以真实速率进行，节奏连贯」（不要写"不要快放"） |
| 手部畸变 / 多手指 | A + D | 补「双手始终在画面内且形态完整可数，动作简洁」；若是精细手部操作（穿针/开锁）→ 归 D，建议改极近景特写或拆段 |
| 想要的特效（分身/幻术/能量）没出来或很糙 | D | 特效动效是能力弱项 → 降预期、拆段做；提示词侧只能补具体视觉描述（半透明蓝青色+扫描线+地面反光这类写法） |

## D 组｜空间与站位症状（wan3.0 已知弱项）

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 躺卧朝向错（头脚反了） | A + D | 必写「头朝画面左侧，脚朝画面右侧，仰面平躺」；这是已知模型缺陷，写死可缓解不能根治 |
| 人物与物体比例失衡（人比车大） | A + D | 补比例锚点：「人物身高约为车顶的 1.2 倍」「人物身高比例与场景尺度协调」 |
| 站位左右漂移 / 两人位置互换 | A | 每人给「画面左/中/右 + 朝向 + 距离」三要素；补「站位与朝向全程不变」 |
| 群戏站位全乱 | A | **先分区再给动作**（左侧两人并肩、中间一人、右侧一人半侧身），并只留一人主动作 |
| 跨镜头/跨段落跳轴（上镜从右出画，下镜也从右入画） | A | 统一左右口径：出画方向与下一镜入画方向必须相反 |
| 该同框的两人不在同一空间里 | A | 补「两人同处一室，同框出现，相距约 X 米」 |
| 人物背对了该面向的目标 | A | 显式写「朝向镜头 / 朝向画面左侧 / 侧身面向对方」，不要只写"看着他" |
| 开场角色直勾勾看向镜头（该演对手戏/该看向道具却盯着镜头） | A | wan3.0 剧情片**开场镜头默认让角色看镜头**（像摆拍）。开场镜头显式写"**四分之三侧身、视线锁定对手 / 落在 <目标物>、不看向镜头**"，并在结尾全局排除"**全程视线只在彼此之间 / 落在 <目标> 上，均不看向镜头**"。除非剧情就是角色对镜独白，才保留看镜头 |

## E 组｜画面稳定性症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 打戏肢体穿模 / 多出手臂 | D | 明说是模型物理交互弱项 → 走拆两段（起势 + 余波）或换局部特写视角；硬跑补「四肢数量清晰可数、肢体轮廓完整不互相穿透」 |
| 物体在接触瞬间消失/变形 | D | 补「接触后物体保持连续形态不消失」；仍不稳则拆段规避接触瞬间 |
| 摔倒/倒地动作果冻感 | D | 改成拍"倒地后的静止状态"，规避过程 |
| 泼水/破碎糊成一团 | D | 换微距局部（碎片落地 / 水珠飞溅特写），穿帮面积小 |
| 画面出现字幕/水印 | A + C | 补「画面干净无字幕叠加」；确认 `watermark=false` |
| 画面莫名闪烁跳变 | A | 多镜头未声明或单镜过短 → 补「生成单镜头」或把每镜提到 ≥2s |

## F 组｜镜头与参数症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 镜头乱晃，要求固定却在动 | A | 前缀写「固定镜头」+ 结尾写「机位与焦距全程不变」，**写两遍** |
| 模型自己切了一堆分镜 | A | 默认行为：分镜不写就自主发挥 → 补「生成单镜头」「一镜到底」 |
| 多镜头时间戳被忽略 | A | 用标准格式「第1个镜头[0-3秒]…第2个镜头[3-6秒]硬切转场，…」，转场与机位写在分镜内容开头 |
| 比例不是竖屏 | C | `ratio` 默认 `adaptive` → 传 `9:16`；提示词里写"竖屏"模型不吃 |
| 时长不对 / 镜头被裁 | C | 多镜头时间戳之和必须 = `duration`；核对后重传 |
| 想让模型自己定长度 | C | `duration=-1` 智能时长 |
| 读剧本文件报错 | C | `file`/`link` 必须 `enable_thinking=true`；两者互斥，各最多 1 个 |
| 结果不可复现，每次都不一样 | C | 固定 `seed` |
| 任务 504 / 长时间不返回 | C | 长任务易超时 → 缩短单次 duration，长内容拆段；PENDING 是排队，不要 cancel |
| 要求"扑镜/冲镜/急速前推/推轨跟拍"却被写成全静止、动感全丢 | A（**过度矫正**） | 分清两种运镜问题：**模型 bug** = 主体在动被误当镜头动、固定镜头仍在晃 → 锁"机位焦距全程不变"；**用户意图运镜** = 扑镜/冲镜/甩镜是剧情要的 → **不能锁死**，要写"是主体朝镜头扑来、镜头同向快速前推配合""镜头随主体运动同向推进"，让主体与镜头**同向**，别把意图运镜误诊成 bug 一键静止 |

> **运镜诊断先分意图**：拿到"运镜错乱"case，先问/判这段运镜是**模型自己乱**还是**用户本来就要的动感镜头**。只有前者才用"机位与焦距全程不变"去锁；后者要保留运镜、只把"主体动 vs 镜头动"的归属写清楚（同向配合）。一律锁死 = 过度矫正，会把用户要的扑镜/冲镜杀掉。

## G 组｜视频编辑 V2V 症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 只想改一处，结果整段都变了 | A | 漏写「**其他保持不变**」→ 补上；同时删掉对原片的复述句 |
| 编辑后画面重演了原来的动作 | A | 把原视频内容又描述了一遍 → V2V 公式只写「编辑对象 + 编辑行为」，删掉所有原片描述 |
| 换角色/换装接缝明显 | B | 参考图与原片**角度或光位不一致** → 换同角度同光位的参考图，或改走重拍 |
| 改台词后音色变了个人 | A | 补「**保持人物音色和语气**，将 XX 的说话内容改为：'…'」 |
| 全局调色把角色肤色/服装本色也改了 | D | 全局编辑无法只作用于背景 → 改走元素编辑逐项替换，或重拍；对连戏敏感的剧集别用全局调色 |
| 视频延长后剧情原地打转 | A | 延长只写**后续新发生的动态**，一句已有画面都不要写 |
| 报 `duration exceed` | C | 输入视频总时长 + 输出 duration 必须 ≤ 30s → 裁短输入或压小 duration |
| 白膜转成片机位被重新设计 | A | 补「保持原有运镜与走位」，并显式写清白模角色到 @图片N 的映射 |

## H 组｜多镜头结构与参考片反推症状

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 分镜被草草带过，后半段几乎没演 | A | 时间戳没首尾相接或求和 ≠ `duration` → 按 `prompt-craft-discipline.md` §1 重排，每段单独核对秒数 |
| 两镜之间跳戏（上镜在窗边，下镜突然在门口） | A | 每段缺"结束状态" → 每段补一句结束状态，并让**上段结束 = 下段起始**（§1 四要素） |
| 分镜切太碎，每镜都不完整 | A | 超了段数卡尺（5s→1 镜 / 8–10s→2–3 / 15s→3–4 / 20–30s→4 封顶）→ 合并到卡尺以内（§1） |
| 一段里塞了推+摇+跟，运镜糊成一团 | A | 一段只留**一个**运镜动作，多的挪到下一段或删掉（§1） |
| 打戏写了一堆动词但打得不知所云 | A | 缺复杂动作五要素 → 按「谁发起 + 从哪出发 + 沿什么路径 + 作用于谁 + 落在哪」重写（§4） |
| 照参考片反推，结果多出原片没有的情节 | A | 反推做了创意外推 → 只写画面里能确认的动作与台词；要加戏另建"创意延伸版"，两版分开交付（§5） |
| 反推出来节奏对不上原片 | A | 分镜切点是估的，不是原片真实剪辑点 → 按真实切点重切时间戳，再核对求和 = `duration`（§5） |
| 多素材串味（把 @图片2 的背景带进主角身上） | A | 开头缺素材职责声明 → 补齐「素材编号 + 正向职责 + 生效时段 + 禁止迁移项」四要素（§2） |
| 排除层写了十几条，反而处处失控 | A | 排除层收敛到 **3–8 项**，只留本条最容易翻车的（§3） |
| 片子能看但"没劲"，开头平、结尾断 | A | 缺最低质量线 → 前 2 秒补钩子动作，结尾补一个明确落点（定格／出画／情绪收束）（§9） |

## I 组｜道具/法器握持与朝向症状（wan3.0 已知弱项）

不对称道具（法器 / 剑戟 / 枪械 / 仪器 / 权杖）在生成中经常握反、握错部位、朝向乱。核心原因：**wan3.0 对参考图的左右/上下方位识别不稳**，会自行镜像；"图片右侧是柄"这类相对方位锚点会失效。

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| 角色拿反法器/兵器（握住刀刃、发光端、枪口等危险端而非手柄） | A + D | **三锚点写法**：① 用**功能命名**代替相对方位（"手柄部分"/"剑柄"/"发光端"/"眼球端"/"尾端"），删除"图片右侧/左侧"这类描述；② 显式写"**双手握住 @图片N 的手柄部分**"，让持握部位入正文；③ 显式写"**发光端/眼球端/刀刃朝向 <画面方位或目标>**"，让另一端有明确指向 |
| 参考图为不对称道具，生成时道具被镜像 | A + D | 同上，一律**功能命名**；如果道具左右对称部件不好区分，在提示词开头做**结构声明**："@图片N 的法器由 A（手柄段）与 B（发光眼球段）两部分构成，手柄段紧贴持握者双手，眼球段悬空指向远方" |
| 双手持物变单手 / 单手变双手 / 握姿飘 | A | 显式写"**双手横持**"或"单手正握，另一手自然下垂"；进阶公式要求运动写幅度+速率+作用效果，握姿也是"作用效果"的一部分 |
| 法器/道具悬浮方向乱（该指向敌方却朝天 / 该水平却竖起） | A | 补朝向锚点：「XX 端朝向 <画面方位或目标>」+「与地面平行 / 与身体呈约 X 度角 / 保持水平横陈于身前」 |
| 参考图带柄道具在生成中被简化（柄消失、造型改成单段） | A + D | 生成会"抹除"参考图细节 → 在正文开头做**结构声明**（哪几段构成、每段视觉特征），并在动作句里点名"手柄清晰可见于持握者手中，末端悬空发光" |
| 多镜头中道具握持位置在镜头间跳变（上镜握手柄下镜握刀刃） | A | 与角色一致性并列声明：结尾补一句"**@图片N 法器的持握部位与朝向全程保持不变**"；跨镜头必须复用同一套功能命名 |
| 道具尺寸与人物比例失衡（法器变得比人还大 / 缩到一半） | A + D | 补比例锚点："法器全长约与持握者身高的 X 成一致"或"法器横陈占据画面宽度约 X"（wan3.0 空间比例已知弱项） |
| 特写镜头中道具突然变形/朝向翻转 | A | 特写镜头结尾单独加约束："道具形态、握持部位与朝向与前一镜头一致，不发生翻转或形变" |

**道具握持通用写法模板**（可套）：

```
@图片1 的<角色> 双手横握 @图片3 的手柄部分（手柄贴近身前腰侧，与地面保持水平），
@图片3 的<另一端>（如发光眼球端 / 剑刃 / 枪管）朝向画面<方位>，
远离持握者身体、悬空指向<目标或空旷方向>。
法器全长约为<角色>身高的 X 成，横陈占据画面宽度约 X 成。
```

> 命中"角色拿反"这类症状时，**不要只补一句"握住手柄"** —— 必须同时给"手柄贴身 + 另一端朝向"两个锚点，缺一个方向就会飘。

## J 组｜文本绿网审核（平台硬拦截，非画面问题）

wan3.0 在**文本输入阶段**就会过一道绿网审核（在生成之前）。命中敏感词时任务直接 `FAILED`，报错 `DataInspectionFailed / Green net check failed for text (input)`，**不产出任何画面**。这与"生成后画面被绿网拦"是两回事——这是提示词文本本身被拦。

| 症状 | 归因 | 处置 |
|---|---|---|
| 任务秒 FAILED，报 `Green net check failed for text (input)` | 平台审核（非提示词写法 bug） | 提示词文本命中敏感词。定位并软化触发词后重试；无法软化到既保留原意又过审时，**如实告诉用户"平台文本审核硬拦，这条跑不了"，让用户决定改写方向或放弃**，不要自作主张删到面目全非 |
| 亲密/暴力/血腥题材反复被文本审核拦 | 平台审核 + D | 常见触发：扯衣领、疯狂亲吻脖颈、压身、掐脖、见血、献祭等。可尝试的软化方向：动作降烈度（"俯身逼近颈侧"替"疯狂亲吻脖子"）、去露骨动词、拉开肢体距离；但**软化本身可能违背用户创作意图**——见下方红线 |

**⚠️ 过度净化红线**：
- 遇到高危物理/亲密动作，**默认不能自己把大尺度内容悄悄改温和了**。用户要的是"保留原始创作意图 + 提示可能的穿帮/审核风险"，不是"替他把戏改干净"。
- 正确顺序：**先按原意写 → 命中弱项/审核风险时"检测→提醒→给方案→用户决定"**（对齐 SKILL §6）。
- 只有在用户**已知情并同意软化**、或文本审核硬拦到根本跑不出时，才动尺度；且要把"改了什么、为什么改"讲清楚，让用户能回退。
- 判断"是模型能力边界(穿帮)"还是"平台文本审核(直接 FAILED)"：前者能出片但画面崩，走 §E/§6 拆段/换视角；后者**根本出不了片**，只能改文本或放弃，别用画面级补丁去治文本级拦截。

## K 组｜动作终态 / 特定音效 / 多人调度（wan3.0 已知弱项）

剧集 case 复测中高频出现的三个坑，都属于"能出片但没做到位"，归 A/D，不是审核问题。

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| **开箱/开门/掀盖类动作只做前半程**（如"打开皮箱"生成成只解开锁扣、箱盖没掀起） | A + D | wan3.0 对"打开"这类动作容易停在预备动作。必须**把动作拆成显式终态**：不写"打开皮箱"，写"解开两侧金属锁扣 → 双手将箱盖向上完全掀起至竖直 → 箱盖保持敞开、露出箱内物品"；并**给足时长**，别让复杂前置运镜（环绕/推进）吃掉动作预算，动作段至少留 3–4 秒 |
| **特定单一音效不生成**（敲门声/关门声/单次撞击声等点状 SFX，写了却听不到） | A + D | wan3.0 的环境底噪/连续声（风、雨、人声、引擎）比点状 SFX 稳。补丁：① 把关键音效**显式定时 + 拟声词**（"第6秒 三下清晰的敲门声『咚咚咚』"）；② **给音效配一个可见的身体反应锚点**（听到敲门声时"肩膀猛地一颤、上身微后仰"），声画双保险，别只靠眼神演；③ 仍可能漏——如实告知音效是 wan3 弱项 |
| **情绪展现平淡**（推镜到脸但情绪没层次、反应太温） | A | 情绪写成**过程 + 身体连锁反应**，不止眼神：警惕→"眉心收拢、屏息、颈部绷紧"；震惊→"瞳孔骤缩、身体一颤、后仰半步、倒吸一口气"。给情绪一个**明确的触发点**（听到声响的那一刻）和**幅度递进**，别全程一个表情 |
| **多人 + 群众 + 威胁源同框，镜头一推近就塌成"美女近景"** | A + D | wan3.0 对"多人复杂调度"会退化到它最熟的单人/双人近景摆拍，丢失叙事。补丁：① **锁固定机位或只做极轻推拉，禁止推到面部特写**（"全程中景固定机位，不推近到任何单人面部"）；② **把威胁源/叙事核心写成反复可见的视觉锚点**（"正面木门在门外持续猛烈撞击下剧烈震颤、门把手哐当作响、门始终紧闭未开"），让模型的注意力挂在事件而非人脸上；③ 多人时明确"各自站位朝向全程不变、只 N 人做主动作" |

> 这三条的共性：**wan3.0 倾向于"回归它最擅长的画面"**（好看的人脸近景、预备动作、连续环境声），会把"动作终态、点状音效、多人叙事"这些吃力的部分省掉。对策统一是——**把想要的结果写成不可省略的显式终态/定时锚点/固定机位约束**，并给足时长与身体反应做双保险。

> ⚠️ **K 组第 4 行的"威胁源写成可见锚点"要看情况**：只有当威胁源本就该在画面内时才这么写。若威胁源按参考图取景应在**画面外**（如门在镜头位置、人物正对镜头方向恐惧），**千万别自作主张把威胁源塞进画面**——见 L 组第 1 行。多人塌陷的正解是"锁机位 + 锁朝向"，不等于"必须把威胁源渲染出来"。

## L 组｜参考场景朝向 / 画面外威胁源 / 环境误生成

延续 K 组的高频坑。核心教训：**别替用户脑补画面里没要求的元素**（多余的门、室内的雨），也别搞反参考图的取景朝向。

| 症状 | 归因 | 最小补丁 |
|---|---|---|
| **威胁源被自作主张塞进画面**（用户只要"人物面对门外威胁、演恐惧"，却把大门/威胁体怼到画面正中当主体） | A（过度发挥） | 先判断威胁源该不该入画。**若参考图取景是"正向/正面"、人物正对威胁方向 → 威胁源(门)就在镜头位置或画面外，画面中不出现门体，机位只拍人物、聚焦表演神情**。显式写"画面外正前方是那扇被撞的门，画面中不出现任何门体，镜头只拍三人"。别把"表演戏"做成"道具展示戏"。 |
| **沿用参考图场景时搞反机位朝向**（把"正向大厅"拍成人物背对镜头朝里） | A | 用全能参考的场景图时，**显式声明"沿用参考场景 @图片N 的正面正向视角"**，并写清人物是"正面朝向镜头方向 / 背对镜头朝里"。朝向一句话定死，别让模型猜。 |
| **暗调场景自行脑补"室内下雨/水渍/湿地面"**（冷蓝光+地面反光+悬疑走廊，模型会补出室内雨丝或满地积水） | A + D | 只要不想要室内雨，就**显式排除**："室内干燥整洁、地面干爽无积水无水渍、室内无任何雨丝水汽"。若剧情需要雨，**限定在窗外**："雨只在窗外、隔玻璃可见，绝不进入室内"。氛围词（冷蓝光/反光）会诱发湿感，需主动锁干。 |
| **推镜到脸但表演依旧温**（K组c 补了身体反应仍嫌平） | A | 把幅度写到位：末段用"倒吸一口冷气、肩膀猛地一大颤、后退半步、瞳孔骤缩瞪到最大、嘴唇大幅张开近乎失声、下巴发抖"这类**大幅度、可见、带生理反应**的动词堆叠，并显式写"表演层层爆发、张力十足，绝不平淡"。温≈动词太文雅，换成更强的生理性动词。 |
| **恐惧情绪过度写成"流泪崩溃"**（写了"眼泪涌上打转"结果角色全程哭脸，用户要的是惊慌/害怕而非悲伤/哭泣） | A | wan3.0 对"泪/哭/泣"类词汇非常敏感，一旦出现就会渲染泪痕湿脸。**"惊慌害怕" ≠ "哭"**——如果剧情是"被突发声响惊吓"，正确的情绪词是：瞳孔骤然瞪大、嘴唇张开发不出声、屏住呼吸、肩膀猛颤僵直、脸色发白、额头微汗、身体本能后缩。**禁止写"眼泪/泪光/泪水/打转/哭/泣"**，除非剧情明确要求角色哭泣。 |
| **提示词里写了"门"字，即使说"不出现门"也会渲染出门**（wan3.0 的正向排除几乎无效） | D（模型注意力） | wan3.0 对**名词性存在感极强**——只要提示词提到"门/door"，模型就会渲染。正向排除("画面中不出现门")对视觉token几乎不起作用。**唯一可靠的方法是整篇提示词完全不出现该物体的名词**。如果需要描述画外敲打声，用"沉闷的撞击声"/"画面外传来重物连续猛击的闷响"代替"敲门声"，全篇彻底避免"门"字。同理适用于所有不想入画的物体——别写名字、别写"不出现XX"，直接让它从文本里消失。 |
| **参考图相似度被提示词描述压过**（R2V 角色完全不像参考图） | A | R2V 全能参考下，角色外观**完全由参考图决定**。提示词里不该出现冲突或多余的外貌描写（肤色/发型/服装/五官细节）。若发现角色不像参考图，**删掉所有外貌描述只保留 @图片N 指代 + 情绪/动作**，让参考图独占视觉权重。此外，画面中过多环境细节描述也会分散参考匹配的注意力——精简环境描写到最少。 |
| **角色动作被误解**（"听到声音恐惧"被渲染成"她自己在敲/她在触碰什么"） | A | 被动反应（听到/感受到）需要**显式锁死肢体**："双手自然下垂、身体不做任何主动动作，只有面部与肩颈做出被动惊吓反应"。不要写"她听到了敲X声"（模型可能把动作归因到她身上），改写成"画面外骤然响起N声沉闷撞击"，主语是声音、不是她。 |

> 🚨 **L 组最重要的一条硬约束（高频反复踩坑）**：R2V 全能参考下，**参考图本身有的元素几乎无法通过提示词删除**——参考图画了什么，就会被继承什么。例：大厅参考图两侧有大门 → 生成的大厅一定有门（提示词写"不出现门"无效）。
>
> **正确判断顺序**：拿到参考图后**先仔细看画面里已有什么**，再决定能不能沿用：
> 1. 参考图里有的元素 = 会被继承的硬约束，接受或换图。
> 2. 若必须去掉某元素，只有三条路：① 换机位/裁切构图把该元素切出画外；② 换一张不含该元素的参考图；③ 完全放弃场景参考图，只留人物参考图，让模型文生场景。
> 3. 三条都不选就得**接受**这个元素作为生成结果。
> 4. **绝对不要靠提示词的正向排除去修——那是无效功**。用户会一遍遍看到同样的问题、白花积分。
>
> ⚠️ **反面教训——不要把"模型脑补"错判为"参考图自带"**：判断参考图有没有某元素时，必须**逐帧仔细看**。地面反光可能只是窗光在木地板上的反射、并无雨丝也无积水——雨往往是模型在暗调冷蓝光+反光地面时自行脑补出来的（见上表第 3 行）。这种脑补型问题必须走"显式锁干"（写"室内干燥、地面干爽、无任何雨丝水汽"），而不是让用户换图。**判错方向会让用户白跑一轮、损耗信任**，写结论前请二次核对参考图。

**硬规则**：

- 一次动 **≤3 处**；超过说明归因没收敛，回去重新定位
- 禁止加无针对性的堆砌词（高质量、8K、电影级、大师作品）

## A/B 复测纪律

1. **一次只动一个变量** —— 同时改提示词和参数，结论不可归因
2. **`seed` 固定** —— 不固定就不叫对比
3. **best-of-3** —— 弱项动作至少跑 3 次再判优劣，单次结果不作结论
4. **每 case 独立 `task_id`，禁止混用**；批量时每个模型/每个变体独立表格
5. 结论用**可复现口径**写：「seed=12345、duration=10、720P，3 次中 2 次肢体完整」，不要写"感觉好了一些"
