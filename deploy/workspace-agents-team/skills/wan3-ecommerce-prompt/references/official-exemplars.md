# 电商优秀范例库

本文件收录**已验证能出好片**的电商 / 广告营销 / 产品展示 / 时尚 / 商业数据类 GoodCase 写法样板。
用法：写新 case 时优先照这里的结构套，比自己从零编更稳。与 `wan3-official-formulas.md` 冲突时以官方公式为准，本文件是"官方公式的电商落地样板"。

> 本库所有参考指代已统一为 `@图片N / @视频N / @音频N` 官方口径；落地时请保持同一口径。
> 电商适用行业：家电、彩妆、汽车、快消、3C、服饰、互联网软件，覆盖"从产品展示到品牌叙事"；设计创意类覆盖产品 UI 交互演示、软件功能动画、数据可视化。

## A. 商品静展 / 包装 / logo·文字（最稳打法）

### A1. 三镜头正反面包装展示（★ 电商标准结构，直接套）
**技法要点**：远景缓推 → 正面占满特写（文字锐利）→ 手翻转到背面展示配料/成分 → 翻回正面。全程 logo/配色/花纹"保持高度统一不变形"。
```
镜头1：远景，木桌场景中 @图片1 的<商品+包装>居中陈列，旁边散落<原料/氛围道具>，镜头缓推靠近；
镜头2：特写，包装正面占满画面，清晰展示<顶部徽章Logo>、<品牌书法字>、<品名>、<N枚胶囊标签"卖点1""卖点2""卖点3">及<主色底色烫金配色>，文字锐利可辨；
镜头3：一只手从上方拿起包装翻转至 @图片2 的背面，展示密排的配料表、营养成分表格、生产商信息及底部条形码，<浅色小字在深底色上清晰可读>，随后翻回正面；
全程产品包装的烫金Logo、文字、<主色>配色与印刷花纹保持高度统一不变形。电商产品展示风格，暖调生活感
```
**为什么好**：把"要看清的文字信息"拆成独立特写镜头，用参考图承载 logo（不让模型生成文字），翻转动作展示背面又不丢正面锚点。对应 SKILL §6 场景1。

### A2. 高级产品发布 / UI·材质动态（3C·互联网软件）
**技法要点**：按 N 张图分镜排时间戳，每段一个 UI/材质动作（paper wipe、mask reveal、card cascade、layout reflow、ease-out 定格），克制留白开场→元素依次浮现→定格。
```
生成<9秒、16:9>高级产品发布动态视频，纯白棚拍，柔和自然光，电影级微距。风格：<Material Design/Apple>，结合<彩色纸张工艺、半透明材质与UI界面>，干净精致。
按N张图分镜：
- 图1（0–1.48s）：<开场克制，仅呼吸浮动> @图片1
- 图2（1.48–3s）：<主面板→卡片→按钮依次浮现，Material ease> @图片2
- 图N（末段）：<最终UI稳定，高亮标语，smooth ease-out定格> @图片N
```

## B. 美妆 / 试色 / 上妆（承接 SKILL §4 美妆弱项）

### B1. 唇釉试色（一句话也能出片，但建议补锚点）
最简写法（只有产品图也能出片）：
```
只有唇釉产品图 @图片1 ，生成模特试色视频，15秒，竖屏，突出唇色效果
```
**落地补丁**（结合本 skill 美妆弱项经验，务必加）：补"唇色以 @图片1 为准全程不偏色"、机位固定、"上唇/下唇同框展示涂抹前后对比"。色号敏感，别让模型自由发挥。

## C. 服装 / 上身试穿 / 多 SKU 展示

### C1. 单模特多动作穿搭展示（★ 上身试穿标准套路）
**技法要点**：一个连续镜头里串"推门全身入画→侧身微抬手推近看细节→转身看面料光泽→端杯定格"，每个动作对应一个展示重点（袖口荷叶边/蕾丝镂空/珍珠扣/缎面光泽）。
```
@图片1 的女孩穿上 @图片2 的<单品A>，下身搭配<单品B和鞋>。场景为<有氛围的街角/店面>。
先从<门口>推门而出，全身入画展示整体穿搭轮廓，<袖口细节>随动作层叠飘动。
然后靠在<道具>旁微侧站立，一手轻抬至锁骨处，镜头推近展示<胸前花纹/扣子精致细节>。
接着她拢了拢发丝转身侧面，<面料>的柔和光泽随身体弧度流动。
最后<端起咖啡杯轻抿>，<袖口>在杯沿旁层层散开，定格收尾。<午后柔和自然光，调性>。
```

### C2. 多人/多 SKU "翻牌式切换"展示（★ 头饰/首饰/多款一次展示）
**技法要点**：N 位人物/SKU 按上传顺序出场，**始终固定画面正中央**，每位停留约 2 秒只做微动（轻微摇头/偏头/抬颌），装饰（流苏/花枝/耳饰）轻微延迟摆动，背景纹样保持静止。切换统一为"水平翻牌式"（绕竖直中轴翻转，翻到最窄处切下一位）。配时间戳分镜"停留展示—翻牌—停留展示"。
```
参考上传的N张关键帧，生成一支<时长、比例>展示短视频。人物始终固定在画面正中央，构图稳定，不要跑位，不要大幅运镜。每位停留约2秒，主要动态为轻微左右摇头、缓慢偏头、微微抬颌或回正，让<商品>得到充分展示。<装饰元素>可有轻微摆动，背景纹样保持相对静止。
切换方式统一为"水平翻牌式切换"：当前画面像竖立在中心的卡片，围绕竖直中轴平滑水平翻转，翻到侧面时短暂变窄，随后下一位从另一面自然出现。切换干净利落，位置不偏移，始终中心对齐。
（附时间戳分镜：0-2s第一位…2-2.4s翻牌…）
```
**为什么好**：多 SKU 展示最容易翻车的是"跑位/大小漂移/切换飞散"，这条用"始终居中+统一翻牌+微动"三把锁全部按住。

### C3. 双主体时尚材质微距（时尚大片·材质卖点）
**技法要点**：纯硬切（Jump Cut）逻辑、面部用 @图片N 锁定、服饰用另一组 @图片N 参考、材质走极近微距特写（皮革折痕金属光泽 / 真丝水波流动 / 皮肤通透绒毛）、高速摄影慢动作。
```
电影级双人时尚大片，极快节奏，纯硬切剪辑逻辑，<胶片质感>，照片级真实，无文字。人物面部完全锁定 @图片1 和 @图片2。
[0-3秒] 硬切，登场与反差，直视镜头。
[3-6秒] 硬切，材质极致特写：参考服饰 @图片3 <皮革折痕金属光泽>；参考服饰 @图片4 <真丝如水波流动，皮肤通透水光肌，可见细微绒毛>。
[后段] 硬切，交错/背靠背/定格。
运镜：快速手持，高速摄影慢动作，纯硬切，无花哨特效。
```

## D. 品牌叙事 / 广告片（从文件·提案生成）

### D1. 品牌态度短片（零功效宣称，情绪驱动）
**技法要点**：从提案文档生成，讲一个小故事（如"清晨三分钟"），全程主角一致，**零旁白、零产品功效宣称**，仅靠画面情绪传递品牌态度，**最后镜头以产品图收尾**。
```
根据我的提案文档，生成<品牌名+产品>广告片——一个关于「<主题>」的故事。<主角从…到…的日常动线>，全程<质感锚点>。全片零旁白、零产品功效宣称，仅靠画面情绪传递「<品牌态度>」。保证主角的一致性。最后的镜头以产品图收尾。
```
**为什么好**：广告合规红线（不夸大功效）用"零功效宣称"直接写进提示词；用"产品图收尾"保证品牌落点。

## E. 商业数据可视化（跨境电商 GMV / 经营月报，从 xls 生成）

### E1. 数据片：严格引用源数据 + 音效节点（★ 强约束模板）
**技法要点**（这是数据片不翻车的关键，务必照抄纪律）：
1. **逐个写死单元格来源与数值**：`左侧是第7行B7单元格的值$1,580`、`增幅由G5相对B5计算`——不让模型自己编数字。
2. **图表洁净约束**：`环形图上没有任何百分比符号、没有任何数字标注、没有任何散落标签，只有纯粹的三段色弧`——防止模型乱标。
3. **数字动画**：`数字从0快速跳动至H7单元格的值$138.1M`。
4. **BGM 必须显式要求并贯穿**：`BGM（必须有，贯穿全片，音量清晰可闻）…旁白出现时音乐不消失、音量略低于人声`。
5. **音效节点对应动作**：色块滑入"嗖"whoosh、数字跳动"咔嗒"键盘音、关键数据弹出清脆"叮"bell。
6. **旁白语气**：`英文，明快自信，语速约2.5词/秒，像季度会做presentation，关键数字处微微加重`。
```
总时长<N>秒，<M>个片段顺序拼接。全片纯白底，柔色色块与简洁线条图表，Apple Keynote式极简商务风格，无衬线深灰字体。
BGM（必须有，贯穿全片，音量清晰可闻）：轻快商务背景音乐，从第一秒起就有，全程不间断，旁白时音量略低于人声。
音效层：色块滑入'嗖'whoosh、数字跳动'咔嗒'键盘声、关键数据弹出'叮'bell。
旁白：英文，明快自信，语速约2.5词/秒，presentation语气，关键数字处微微加重。
片段1：<从B7单元格$1,580 到 G7单元格$3,460，中间箭头，底部标签H8单元格+45.7%>，数值必须与单元格完全一致…
片段N：环形图只有三段色弧，图表上无任何百分比/数字标注，中央大号数字从0跳动至H7单元格$138.1M…
```

## F. 电商 V2V 编辑（复用老素材）

元素/时序/全局编辑范例，全部遵循 SKILL §3「编辑对象 + 编辑行为」，只写要改的、加「其他保持不变」：

| 电商诉求 | 范例写法 |
|---|---|
| 换人换装（保留动作轨迹） | 「@视频1 中的滑板男人替换为一位短发女人，穿运动背心和宽松工装裤，**保留原视频中的棒球帽、护膝护肘等护具**，滑板动作、运动轨迹和滑板场背景**完全保持不变**」 |
| 时序参考换人+换衣 | 「参考 @视频1，将 @视频1 中的滑板男人替换为 @图片1 中的女人和衣服，注意：**只替换人物**，保留原视频中滑板动作、运动轨迹和背景完全保持不变」 |
| 多图换装+换配饰 | 「@视频1 中的女人戴上 @图片1 中的帽子，自然贴合头型。男人戴上 @图片2 的帽子，赭棕色衬衫换成 @图片3 中的蓝色水洗宽松牛仔衬衫，翻领敞开、袖子卷至前臂。两人的动作、服装和画面其余部分保持不变」 |
| 加卖点道具（光影一致） | 「@视频1 中女人右侧桌面空位处新增 @图片1 中的花瓶，**花瓶光影与窗户自然光方向一致**，自然融入木桌场景。女人的动作和画面其余部分保持不变」 |
| 清理穿帮物 | 「将 @视频1 中泳池水面上的蓝色和黄色游泳圈全部去掉，池边石板地上的画纸、颜料罐、画笔和黑色收纳箱也全部去掉，**用周围泳池水面和石板地面自然填充**。仅保留女人漂浮在泳池中，姿态动作和背景保持不变」 |
| 去除遮挡物（露出商品/脸） | 「@视频1 中女人头上的帽子去掉，露出自然发型」/「女人的墨镜去掉，露出自然眼妆和眼神」——其余保持不变 |
| 整体补光提质 | 「@视频1 整体提亮光线，采用美剧质感的柔和三点布光，消除面部右侧硬阴影，让五官轮廓均匀受光，肤色自然通透…保持画面整体影调统一，动作和内容不变」 |

**电商 V2V 关键纪律**（范例共性）：换人换装时**逐项点名要保留的护具/道具/背景/动作**，加道具时**显式写光影方向与融入**，去除物时**写清用什么自然填充**。

## G. 从这批范例提炼的通用增益（写任何电商 case 都适用）

1. **"要看清的信息"独立成镜头**：logo、配料表、卖点标签、色号，都拆成正面占满特写，别塞进运动镜头里一晃而过（A1）。
2. **多 SKU/多模特必上"三把锁"**：始终居中 + 统一切换方式（翻牌/硬切）+ 每个只做微动（C2）。
3. **数字/文字信息一律"承载优先、引用锁死"**：参考图承载 logo，单元格锁死数值，图表禁止乱标（A1、E1）。
4. **广告合规写进提示词**：不夸大就写"零功效宣称"，要落点就写"产品图收尾"（D1）。
5. **声音层对电商同样是硬约束**：数据片 BGM 要"必须有、贯穿、旁白时压低"，音效要对应具体动作节点（E1）；口播带货六要素齐全（SKILL §2）。
6. **selective color（局部上色）**是低成本高级感技法：背景黑白 + 逐项列出保留彩色的元素（商品/logo/主色），适合服饰、快消强调主体。
