## 二、声音取词清单

**音效类目**（可作为音效写作清单）：
脚步声、敲门声、物体坠地、撞击声、火焰燃烧声、游戏音效（8-bit）、电子/故障声、ASMR、动物叫声、键盘声；
环境音分自然环境 / 城市环境 / 特定空间；
BGM 分情绪音乐 / 卡点音乐 / 轻音乐。

**人声类目**：单人说话、多人对话、音色指定、方言（如地道京腔）、唱歌。

## 三、值得抄的三个写作手法

1. **声音与画面动作逐点对齐**：写「每一次弹跳精确同步的有节奏的敲击声」「伴随着逐渐变弱的清脆撞击声」—— 音效跟着物理衰减写，比只写"有弹跳声"可控得多。
2. **台词直接内嵌在画面叙述里**：`…嘴部自然开合，用地道的京腔说道："哟，吃了么您呐？"` —— 口型描述 + 台词引号 + 口音，三件一起给。
3. **无人声要显式声明**：如「没有对白或人声；环境音包括树叶轻柔的沙沙声…」—— wan3.0 默认有声，这条尤其重要。
