# wan3.0 官方提示词公式 —— 七大公式与控制口径

> 本文件是 wan3.0 提示词写法的**最高依据**：七大公式 + 参考指代口径 + 默认行为控制。
> 与其他参考文件冲突时**一律以本文件为准**；美学控制层的取词见 `aesthetics-lexicon.md`。

模型具备一句话成片能力，但**描述越完整、精确、丰富，成片品质越高、越贴近预期**。以下七个公式按使用场景选用，可叠加。

---

## 1. 基础公式（新手 / 想要想象力）

```
提示词 = 主体 + 场景 + 运动
```
即「谁 + 在哪里 + 干什么」。

- **主体**：视频的主要表现对象。人、动物、植物、物品，或非物理真实存在的想象物体。
- **场景**：主体所处环境，含背景与前景。真实空间或虚构场景均可。
- **运动**：主体的具体运动 + 非主体的运动状态。可以是静止、小幅度、大幅度、局部运动或整体动势。

> 简单自由的提示词反而更容易生成有想象力的画面 —— 追求"意外惊喜"时故意少写。

## 2. 进阶公式（有经验 / 追求质感与故事性）

```
提示词 = 主体 + 场景 + 运动 + 美学控制 + 风格化 + 音效
```

| 成分 | 写什么 | 示例 |
|---|---|---|
| 主体描述 | 主体外观特征细节，形容词或短句列举 | "一位身着少数民族服饰的黑发苗族少女"；"一位来自异世界的飞天仙子，身着破旧却华丽的服饰，背后展开一对由废墟碎片构成的奇异翅膀" |
| 场景描述 | 主体所处环境的特征细节 | 形容词或短句列举 |
| 运动描述 | 运动的**幅度 + 速率 + 作用效果** | "猛烈地摇摆"、"缓慢地移动"、"打碎了玻璃" |
| 美学控制 | 光源、光线环境、景别、视角、镜头、运镜 | 词典见 `aesthetics-lexicon.md` |
| 风格化 | 画面风格语言 | "赛博朋克"、"勾线插画"、"废土风格" |
| 音效 | 背景音效、背景音乐、人物台词、旁白，**并可描述音色** | "低沉混合的声音"、"可爱的声音" |

## 3. 图生 / 首尾帧公式

```
提示词 = 运动 + 运镜
```

首帧或首尾帧图像**已经确定了主体、场景与风格**，因此提示词主要描述**动态过程与运镜需求**。

- **运动描述**：结合图中已有元素（人物、动物）描述其动态过程，如奔跑、打招呼；用形容词控制程度与速度，如"快速地"、"缓慢地"。
- **运镜**：有特定要求就写"镜头推进"、"镜头左移"；**希望镜头不动就写"固定镜头"强调**。

> 推论：图已经承载的外观信息**不要在提示词里复述**，那会稀释模型对动作指令的注意力。

## 4. 声音公式

```
提示词 = 人声 + 音效 + 背景音乐（BGM）
```

声音描述是视频中声音要素**及其随时间变化**的描述，用来指导声音内容与氛围，使其与画面叙事精准配合。

**人声** = `"角色说话的内容"` + 情绪 + 语调 + 语速 + 音色 + 口音（**六要素**）
> 示例：一个男人在讲脱口秀，他说道："好好学习，天天向上"，语气轻松，语速适中，声音清亮，美式英文。

**音效** = 音源材质 + 行为 + 环境音（**三段**）
> 示例：一个玻璃小球从桌面掉在木质地面上，发出"砰"的声音，室内安静环境。

**背景音乐** = 背景音乐/配乐 + 风格（**两段**）
> 示例：雨夜，阴森窄小的走廊，尽头有一扇窗户，配有悬疑风格背景音乐。

## 5. 参考生视频公式（全能参考）

```
提示词 = @参考对象 + 动作 + 台词
```

- **@参考对象**：用 `@` 引用参考素材。多个素材**按顺序排列**：`@图片1`、`@视频2`、`@音频1`。
  **可以在提示词的不同位置多次 @ 同一个对象**，用来精准控制参考意图。
- **动作**：参考对象的运动状态 —— 静止、表情情绪变化、肢体动作、外力动作、位移变化。
- **台词**：参考对象的说话内容，支持**单主角说话**或**多主角对话**；台词可指定音色，写法是**在台词同句内**加「音色参考 @音频1」。
- **视频时序参考**：可以只参考视频的**时序特征**，如"参考 @视频1 的运镜方式"（也可参考其动作、特效）。
- **白膜参考**：输入 3D 白膜预览视频，写法为「将 3D 预览视频转化为正式成片，把预览视频中……换成……角色」。

> 官方示例（注意 @ 的位置与重复引用）：
> 这是一个充满童趣的童话场景。@图片1 在草地上蹦跳着玩耍，@图片2 在旁边的一颗苹果树下弹奏钢琴，一颗苹果掉到了 @图片2 的头上，@图片1 参考 @音频1 的音色，开心地指着 @图片2 说："你要变成科学家了！"。

> ⚠️ **音色引用实测有效句式**：音色参考必须与台词**同句、紧贴台词**，如「@图片1 用惊喜的声音说："<台词>"，音色参考 @音频1」。前置的「提取 @音频1 中的音色特征，并让角色说出以下台词…」这类提取式声明**不生效**，改写历史 prompt 时一并替换。

> ⚠️ **写法提醒**：不带 @ 的「图1 / 视频1」是旧写法，不再使用。**wan3.0 官方口径是带 @ 的「@图片1 / @视频1 / @音频1」**（"图片"是全称，不是"图"）。

## 6. 多镜头公式

```
提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容
```

支持生成包含多个镜头的**连贯叙事**视频，精准控制镜头结构、机位与时间，并在多镜头间保持**主体、场景、氛围**一致。

- **总体描述**：概述整个视频内容 —— 故事主题、叙述风格、主要情感或核心事件，便于模型把握全局叙事方向。
- **镜头序号**：为每个镜头编号，区分场景/段落顺序。
- **时间戳**：标明每个镜头在视频中的具体时间范围，确保内容与时间线对应。
- **分镜内容**：每个分镜中主要角色/物体的具体行为 —— 动作、语言、表情、姿态，**可参考单镜头写法**。

> 官方示例：
> 这个故事以第三人称视角，讲述了一个关于放弃与重拾希望的短剧。
> 第1个镜头[0-3秒]一个男孩在操场的角落独自坐着，低头望着手中的信纸，随后轻轻叹气，眼神中透露出迷茫。
> 第2个镜头[4-6秒]硬切转场，固定机位，聚焦于男孩的眼睛，泪光闪烁，带着失落和无助。
> 第3个镜头[7-10秒]硬切转场，场景转至一间简朴的教室。一个女孩眼神温和而坚定，穿着朴素的衣着，面带温和而坚定的笑容，走到男孩的身边安慰他。

要点：官方示例用「第N个镜头[a-b秒]」格式，转场方式（**硬切转场**）与机位写在分镜内容开头。

## 7. 视频编辑公式（V2V）

```
提示词 = 编辑对象 + 编辑行为
```

支持**文本 + 图像 + 视频 + 音频**组合输入作为控制条件，在画面结构、剧情走向、局部细节、时序变化上均可控制与修改。四类玩法：

**① 元素编辑** —— 用简单清晰的文字直接描述要修改的语义内容
- 添加："男人戴上红色的帽子"
- 修改："把猫换成狗"
- 删除："去除草地上的猫"
- 有图片参考时指定图中具体物体："把视频中男人的衣服换为图片中的红色外套"
- 多张参考图按顺序编号："让视频中的男人穿上 @图片1 中的衣服和 @图片2 中的裤子"

**② 全局参数编辑（风格/光线/色调/氛围/天气）**
- 天气："视频修改为阴天"
- 色调："修改为暖色调"
- 风格："把视频改为2D卡通风格"；有图参考则"把视频改为图中的2D卡通风格"
- **希望其他信息不变时，额外写「其他保持不变」**

**③ 时序编辑** —— 修改动作、台词等随时间变化的信息
- 动作："让视频里的男人拿起水杯，喝下一口水"
- 台词（可强调保音色）："保持人物音色和语气，将女生的说话内容改为：'Hello World'"

**④ 视频延长** —— 画面内容、风格、布局已确定，**只写后续动态变化**
- "男人继续往前走，突然摔倒在地上"

## 8. 其他控制（不写 = 模型自主发挥）

对于分镜、台词、背景音乐三个维度，**提示词不规定，模型就会自己发挥**。要精准控制必须显式写：

| 维度 | 不写会怎样 | 精准控制写法 |
|---|---|---|
| **分镜** | 模型结合提示词自行运镜，可能出单镜头，也可能出任意数量的多镜头 | 控制个数与时间戳：「镜头1 xxx，镜头2 xxx」或「镜头1[0-3秒]xxx，镜头2[3-6秒]xxx」<br>**强控一镜到底**：写「**生成单镜头**」「**一镜到底**」 |
| **台词** | 模型自由发挥添加台词 | 写了 `xx说："xxx"` 模型会**保持该台词内容不变**；<br>**不想要台词**：强调「**全片无台词**」 |
| **背景音乐** | 模型根据题材和内容自行发挥 | **不想要 BGM**：写「**无背景音乐**」 |

> 这三条是 wan3.0 最容易翻车的默认行为。声音开着（`audio=true` 默认）而提示词不写声音层 = 模型自己配旁白和 BGM，交付时被客户投诉"哪来的声音"。

## 9. 公式选用速查

| 需求 | 用哪个公式 |
|---|---|
| 没参考素材，纯文字起片 | §1 基础 → 不够就上 §2 进阶 |
| 有首帧图 / 有首尾帧 | §3（只写运动+运镜） |
| 有角色图、商品图、参考视频、音色 | §5 参考生视频（`@图片1` 指代） |
| 要控声音（台词/音效/BGM） | §4 声音公式，叠加到上面任一公式尾部 |
| 要多段叙事、要控镜头数与时间 | §6 多镜头 |
| 已有成片要改（换物、改色调、改台词、续拍） | §7 视频编辑 |
| 不想要切镜 / 不想要台词 / 不想要 BGM | §8 三条显式声明 |
