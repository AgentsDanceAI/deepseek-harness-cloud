# 品牌 TVC / 创意广告蓝图（电商高阶拍法）

客户要"品牌感 / 广告大片 / 创意反转 / 无标白牌"类商品视频时套用本文件。核心不是堆"高级、电影、质感"这类形容词，而是把商品、场景、演员、镜头、光线、声音和反转机制组织成模型能稳定执行的一条广告。

> **三条前提，优先级高于本文件一切建议**：
> 1. **客户已有提示词/脚本/分镜一律遵循**（SKILL §1.1 改写纪律）：本文件只补技术层与结构化写法，不改客户的动作、场景、台词与叙事结构。
> 2. **时长一律以客户指定为准**：节拍骨架按实际 `duration` 等比缩放，不锁死任何固定秒数；时间戳从 0 起、首尾相接、求和 = `duration`（`prompt-craft-discipline.md` §1）。
> 3. 所有约束写成**正向排除**：`negative_prompt` 已废弃，正文里的否定句会触发删镜（`ecommerce-diagnosis.md` 零节 #8）。

---

## 1. 六拍节奏骨架（按 duration 等比缩放）

**钩子 → 建立 → 升级 → 反转前（埋线索）→ 反转 → 商品英雄镜头收尾**

| 拍 | 时长占比 | 职责 |
|---|---|---|
| 钩子/阈值 | ~17% | 主体、悬念或强视觉动作立刻出现 |
| 建立 | ~20% | 场景与核心机制交代清楚 |
| 升级 | ~20% | 动作或情绪推进一档 |
| 反转前 | ~17% | 埋下至少一个可见线索 |
| 反转 | ~13% | 一次清楚的反转，不贪多 |
| 英雄镜头 | ~13% | 商品正面稳定定格 / 落版状态 |

- 30s 参考切分：0–5 / 5–11 / 11–17 / 17–22 / 22–26 / 26–30；客户给 20s 就等比压缩；**≤10s 砍掉反转**，只留「钩子 → 核心动作 → 英雄镜头」三拍
- **稳定结构五件套**：一个固定主场景、一个核心动作或视觉机制、1–2 个角色、至多一次反转、一个英雄镜头收尾
- **结尾状态必须与开头不同**（打开了/倒满了/点亮了/用过了），不要原地收场
- **回避清单**（与 wan3.0 弱项对齐）：频繁换景、连续复杂变形、多人群像、镜面复杂同步、高速调度、多商品复制、多次反转、无动机的粒子与光斑
- 交付前照常过 `prompt-craft-discipline.md` §9 最低质量线

## 2. 反转机制（一条只选一个，必须服务商品）

| 机制 | 玩法 | 适合品类 |
|---|---|---|
| 微距世界揭示 | 前段像一个辽阔世界，反转拍揭示为商品表面/液体/泡沫/乳霜/织纹 | 饮料、护肤、衣物、口红、香水、咖啡 |
| 情感叙事误导 | 观众以为人物在离别/追赶/等待，结尾揭示真实关系或商品功能 | 行李箱、跑鞋、雨伞、腕表、耳机 |
| 光学折射揭示 | 透过瓶身/水滴/玻璃/镜片折射，反转拍出现真实空间 | 矿泉水、香水、护肤、玻璃杯、眼镜 |
| 阴影隐喻揭示 | 前半段的城市/山脊/房间轮廓，最终是商品投下的影子或表面结构 | 帽子、鞋、家具、雨伞 |
| 时间/状态倒流 | 前段展示结果或困境，后段倒流恢复，揭示使用前后 | 清洁、护肤、衣物、咖啡、家电 |
| 房间/光线响应 | 空间、光线、温度或声音对商品启动做出可信响应 | 咖啡机、耳机、灯具、香氛、家居 |

三条纪律：
- **反转必须可读**：反转前的段落至少埋一个观众看得见的线索
- 结尾**不得靠突然出现的新角色、新地点、新设定、新商品**解决
- 反转是给商品服务的，不做纯炫技；反转后落点必须是商品

## 3. 商品连续性锁八查（写排除层前先过一遍）

| # | 锁项 | 写什么 |
|---|---|---|
| 1 | 形状比例 | 高矮、宽窄、圆角、曲面、厚薄、透明或实心 |
| 2 | 材料颜色 | 玻璃/金属/织物/皮革/塑料/陶瓷、哑光或高光 |
| 3 | 部件数量与位置 | 瓶盖、喷头、表冠、鞋带、把手、按钮、缝线 |
| 4 | 物体精确数量 | 几只鞋、几瓶水、几只杯（正面计数：「共 N 件，不多不少」） |
| 5 | 朝向尺度 | 正面/侧面/倒置、开启角度、相对手掌或桌面的尺寸 |
| 6 | 液位 | 满/半满/三分之一、泡沫高度、凝露范围 |
| 7 | 开合状态 | 盖子开或关、拉链开或合、伞面是否打开 |
| 8 | 干湿/破损状态 | 干燥、微湿、凝露、完好无划痕 |

- **有参考图**：外观类（#1–#3）一律写「以 @图片N 为准、全程恒定」，不复述具体颜色材质（SKILL §5 铁律 4）；只把**状态类**（#4–#8）写成显式锁，因为参考图承载不了"半满""盖子开着"这类随时间变化的状态
- **无参考图 T2V**：八项在主体句写明具体值，排除层再声明「全程保持不变」
- 高频漂移件点名锁：瓶盖、喷头、拉链、鞋带、杯沿、按键这类小件最容易漂，写「XX 的位置与形态全程不变」

## 4. 演员连续性锁

- 默认一名演员，剧情确需时最多两名；两人时写清**相对位置与关系**，并声明「全片仅这两人出镜，背景无路人」（对齐 SKILL §1.2 单人锁）
- 锁五项：年龄段、发型、服装（颜色+单品名，多镜头逐镜复述）、体态与动作方式、**手部使用**（谁拿商品、用哪只手、中途是否换手——换手是接触错误的高发点，不换就写"全程右手持握"）
- 正向排除：五官与体态全程稳定、双手在画面内且手指可数、双脚与地面接触自然

## 5. 零 Logo / 白牌模式（正向写法）

客户要求无标 / 白牌 / 去 logo / 空白包装时，这是**最高优先级硬门槛**，且必须**逐位置正向覆盖**——只写一句"无 logo"必漏，写"不得出现 logo"会触发否定存在锁。参考写法：

```
商品与包装表面为素面无印刷；服装鞋帽为纯色无图案无字母；道具、家具、车辆与电子屏幕均为无文字的素面物体；背景墙面与路面干净无标识；画面干净无字幕无水印，纯实拍质感。
```

- 易漏位置自查：商品、包装、服装、鞋帽、道具、建筑、车辆、车牌、电子界面、路牌、背景、字幕、水印
- **有参考图且图上带品牌字样** → 先提醒客户：参考图承载外观，图上的 logo 大概率被保留，零 logo 需要先修图或换素材，靠提示词清除不可靠
- 收尾落版：零 logo 模式下英雄镜头为纯视觉定格，不虚构品牌字样、口号与片名文字

## 6. 摄影与光线（写"物理作用"，不堆词）

- **焦段写作用，不只报数字**：35mm 交代商品与空间关系；50mm 拍手部与商品接触；85mm 商品英雄镜头/人像压缩；100mm 微距拍材质、液体、织纹、泡沫、喷雾
- **一段一个机位动作**（对齐 `prompt-craft-discipline.md` §1）：缓慢前推、侧向跟随、轻微俯仰、焦点迁移、遮挡转场，任选其一；强调真实摄影机惯性，同一段里推拉摇移环绕不并存
- **光线必须有动机**：窗光、实际灯具、日光、屏幕光、反射光、商品自身功能光——写清方向、衰减与打在什么反射面上
- 质感正向排除（挑本条真实会踩的 3–8 项）：皮肤质感真实、高光柔和滚降、阴影层次可读；光源方向全程一致；画面亮度稳定无闪烁；物体受重力自然放置；画面无来源不明的粒子与光斑

## 7. 声音（品牌 TVC 默认同步现场声）

- 默认**不配乐**：写「无背景音乐」+ 与画面同步的现场声——手指接触、布料摩擦、玻璃/金属/纸张触碰、液体流动、机械启动、脚步、室内空气声与房间混响（按官方音效三段"音源材质+行为+环境音"写）
- **商品功能是放音乐**（音箱、耳机）时，音乐只能在**可见或可听的启动动作之后**进入，并与镜头同步
- 客户明确要 BGM 才写，按官方两段公式（配乐 + 风格）

## 8. 多版本纪律（同一商品出多条创意版）

- 版本之间**至少改变三项**：戏剧机制 / 镜头逻辑 / 场景策略 / 商品与人物关系 / 反转类型 / 光线动机——只把"高级"换成"温暖、奢华、未来感"不算新版本
- 每条都写全建议参数、商品锁、场景、声音与排除层，**不得写「同上」「沿用上一条」**
- 场景策略选型：影棚实拍最稳定，适合高端材质与英雄镜头；家居置景适合情感误导与功能自然露出；户外生活方式适合鞋/箱/伞/水，但避开人群与高速调度；纯 CG 适合微距世界与液体结构揭示，仍要保持可信物理
