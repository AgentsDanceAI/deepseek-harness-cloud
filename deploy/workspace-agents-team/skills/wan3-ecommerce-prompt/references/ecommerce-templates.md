# 电商九类拍法 × 品类模板

用法：挑场景 → 复制模板 → 把 `<>` 里的内容替换 → 逐条过 SKILL.md §5 八条铁律。
所有模板默认已含**声音层**与**正向排除层**，不要删。

> 指代口径按官方 wan3.0：`@图片1` / `@视频1` / `@音频1`（带 @、用全称、各类型分开计数）。
> 不要台词写「**全片无台词**」，不要配乐写「**无背景音乐**」，不要切镜写「**生成单镜头**」——这是官方明确的控制词。
> 完整公式与控制口径见 [`wan3-official-formulas.md`](wan3-official-formulas.md)。

### 多素材时先写一段职责声明

素材超过一个（商品图 + 场景图、主播视频 + 商品图、多 SKU 图）时，模板正文前先加一段声明，四要素齐全：**素材编号 + 正向职责 + 生效时段 + 禁止迁移项**。这能把"背景图的元素跑进主体""A 的图案跑到 B 上"这类串味问题挡在前面。

```
@图片1 提供商品的外形、颜色与包装文字，全片生效；图中原有背景与摆放道具不参与生成。
@图片2 只提供台面材质与环境光氛围，全片生效；图中出现的其他物品不进入画面。
@视频1 只提供主播的形象与讲解节奏，全片生效；原视频的背景、字幕与商品不参与生成。
```

白底棚拍商品图（电商最常见素材）专用声明，直接套：

```
@图片1 只锁定商品的几何比例、材质颜色、部件数量与位置、开合状态与关键表面细节，全片生效；图中白底背景、棚拍构图角度、影子方向与附带文字均不参与生成。
```

写法细则与更多例子见 [`prompt-craft-discipline.md`](prompt-craft-discipline.md) §2。

## 1. 商品静展（wan3.0 最稳打法）

**形态**：全能参考（`reference_image`：商品图 + 可选场景图）
**推荐参数**：`duration=5` `ratio=1:1` 或 `9:16` `audio=false`

### 1A 环绕展示
```
柔光，侧光，中近景，中心构图，平拍，浅景深，<暖/冷>色调，环绕运镜。
@图片1 的商品置于 @图片2 的<台面>中央，镜头绕 @图片1 缓慢环绕 <180/360> 度，
<材质细节>随光线角度变化产生流动高光，正面 logo 始终朝向镜头且保持清晰不形变。
全片无台词，无背景音乐，仅保留极轻的室内环境底噪。
商品轮廓与比例全程保持稳定，背景保持洁净单一，焦点始终锁定商品。
```

### 1B 固定机位微动（循环素材）
```
柔光，日光，特写，中心构图，平拍，固定镜头，低饱和度。生成单镜头。
@图片1 的商品静置于浅灰无缝背景中央，仅光影随时间极缓慢地从左侧移向右侧，
@图片1 表面高光带随之平移，<细节部位>反光逐渐显现。
全片无台词，无背景音乐，环境完全安静。
商品位置、朝向、大小全程不变，机位与焦距全程不变，画面干净无叠加图形。
```

### 品类微调
| 品类 | 前缀调整 | 材质动作词 |
|---|---|---|
| 服装 | 柔光、边缘光、中景 | 布料垂坠感、纤维绒面在侧光中起绒 |
| 日用 | 柔光、平拍、特写 | 哑光/亮面塑料反光、金属拉丝纹理 |
| 食品饮料 | 暖色调、硬光点缀、微距 | 表面油润光泽、糖霜颗粒、冷凝水珠 |
| 美妆个护 | 高光泽、边缘光、微距 | 膏体细腻拉丝、瓶身玻璃折射、粉质哑光 |
| 3C 数码 | 冷色调、硬光、低饱和度 | 阳极氧化磨砂、屏幕黑镜反射、接口金属边 |
| 汽车 | 极端全景转中景、日落、硬光 | 车漆倒影流动、轮毂辐条、腰线高光带 |

## 2. 口播带货

**形态**：全能参考（主播图/视频 + 商品图），主播挂 `reference_voice` 锁音色
**推荐参数**：`duration=8~10` `ratio=9:16` `audio=true`

```
柔光，实用光，中近景，中心构图，平拍，干净的单人镜头，暖色调，固定镜头。
@视频1 的主播手持 @图片1 的商品置于胸前偏右，商品正面朝向镜头，另一只手自然摆动配合讲解。
@视频1 面向镜头微笑说道："<台词，≤ 时长×4 字>"
情绪<亲切自信/沉稳专业/热情急促>，语调<上扬/平稳>，语速<略快但吐字清楚>，声音<明亮/低沉>，<标准普通话/带轻微南方口音>。
无背景音乐，仅保留轻微室内环境音。
商品在画面中的位置与朝向全程稳定，包装文字保持清晰完整，双手始终在画面内且动作简洁。
```

**要点**：
- 台词字数 ≈ 时长 × 4 字，超了会截断（长口播截断是通用风险）
- **人声六要素**（官方声音公式）：`"内容"` + 情绪 + 语调 + 语速 + 音色 + 口音，缺一项模型就自由发挥一项
- 音色引用要**与台词同句、紧贴台词**：「@视频1 用亲切的声音说："<台词>"，音色参考 @音频1」——前置的"提取 @音频1 音色特征"式写法实测不生效；与参数级 `reference_voice` 可同时用
- 想换台词不换人：固定 `seed` + 只改引号内容；已有成片直接走 V2V 时序编辑（§8）
- 多主播对话：每人各挂一段 `reference_voice`，比在提示词里描述音色可控

## 3. 材质微距 / ASMR

**形态**：全能参考 或 T2V
**推荐参数**：`duration=5` `ratio=1:1` `audio=true`（音效是卖点）

```
ASMR，微距特写，柔光，侧光，中心构图，浅景深，固定镜头，<色调>。
<工具/手指>以匀速<接触/按压/划过> @图片1 的商品表面，
接触处<材质>产生<形变/凹陷/纹理起伏>，随即缓慢回弹，边缘细节持续可见。
音效为<音源材质> <行为>发出的"<拟声词>"声，<环境音>，室内安静环境；全片无台词，无背景音乐。
商品表面纹理与颜色全程保持一致，动作以真实速率进行，节奏连贯，机位与焦距全程不变。
```

**音效写作法（官方公式：音源材质 + 行为 + 环境音）**：跟着物理衰减写，不要只写"有声音"。
> ✅「一个玻璃小球从桌面掉在木质地面上，发出"砰"的声音，室内安静环境」（官方示例结构）
> ✅「以清脆的敲击声撞击桌面…伴随着逐渐变弱的清脆撞击声，每一次弹跳精确同步的有节奏的敲击声」
> ❌「有弹跳的声音」

## 4. 开箱 / 使用演示 ⚠️ 高危

**先走 SKILL.md §4 的"检测→提醒→方案→用户决定"流程再写。**

**形态**：首帧（锁死起始构图）或 全能参考
**推荐参数**：`duration=5`（别贪长）`audio=true`

### 4A 规避型（推荐）——拆两段，跳过高危瞬间
```
# A 段：张力铺垫（不做开启动作）
微距特写，硬光，中心构图，浅景深，固定镜头，冷色调。
一只手稳稳握住 @图片1 的<罐体/包装>，指腹搭在<拉环/封口>边缘施加轻微压力，包装表面出现极细微的受力形变。
音效为指腹摩擦包装的轻微"沙沙"声，室内安静环境；全片无台词，无背景音乐。
包装轮廓与文字全程保持完整清晰，手指数量与位置稳定，机位与焦距全程不变。

# B 段：结果状态（已完成开启）
微距特写，柔光，中心构图，浅景深，固定镜头，冷色调。
@图片1 的<罐体>已处于开启状态，杯口液面因轻微晃动产生连续起伏的波纹，气泡自底部持续上升并在液面破裂。
音效为气泡破裂的细密"嘶嘶"声与液体晃动的轻响，室内安静环境；全片无台词，无背景音乐。
容器轮廓与液面边界保持连续完整，机位与焦距全程不变。
```

> A 段末帧可直接作为 B 段 `first_frame`；或 A 段跑完走**视频延长**（§8）接 B 段，衔接更自然。

### 4B 硬跑型（用户坚持一镜完成）
在动作句后面追加物理约束，并建议 best-of-3：
```
…拉环沿固定轨迹被向上提起约 30 度后停止，罐口出现完整环形开口。
罐体轮廓与拉环形状全程保持完整，金属边缘连续无断裂，液体流线连续，手指数量与位置稳定。
```
配 `seed` 固定，跑 3 次挑片。

## 5. 上身试穿 / 走秀

**形态**：全能参考（人物图/视频 + 服装图 + 可选场景图）
**推荐参数**：`duration=8` `ratio=9:16` `audio=false` 或轻 BGM

```
柔光，边缘光，中景转中近景，中心构图，平拍，暖色调，镜头缓慢推进。
@视频1 的模特身穿 @图片1 的服装，在 @图片2 的场景中以从容步态向镜头方向走来约三步后停下，
@视频1 转身半侧向镜头，衣摆与<面料>随动作产生自然垂坠与摆动，肩线与腰线轮廓保持清晰。
全片无台词，配有<轻快/舒缓><风格>背景音乐。
人物身体比例与服装版型全程保持稳定，服装图案与颜色保持一致，双脚落地方向与行进方向一致。
```

**要点**：
- **比例锚点必写**（wan3.0 有人物比例失衡的已知问题）：「身体比例保持稳定」「肩线腰线轮廓清晰」
- 面料动态词：垂坠、飘动、绒面起绒、硬挺不塌、褶皱随步伐开合
- 步态给节奏：「以从容步态走三步」比「走路」可控
- 一衣多穿：同一段走秀成片走 V2V 元素编辑换衣，比重跑更省成本（§8）

## 6. 前后对比 / 换色（首尾帧专属）

**形态**：`first_frame` + `last_frame`（**与全能参考互斥**）
**推荐参数**：`duration=5` `audio=false`

首尾帧模式下按官方图生公式**只写运动 + 运镜**，不要描述首帧和尾帧长什么样：
```
固定镜头，柔光，中心构图。
画面通过表面颜色自左向右均匀铺展的方式完成过渡，过渡过程连续平滑无跳变，
商品轮廓、位置、大小在整个过程中保持完全不变，背景保持静止。
全片无台词，无背景音乐。
```

**常见错误**：把首尾帧的外观又抄一遍进提示词 → 抢注意力、易崩。

## 7. 场景种草短片

**形态**：T2V（无素材）或 首帧（有主视觉）
**推荐参数**：`duration=8~10` `ratio=9:16` `audio=true`

```
<日光/黄昏>，柔光，侧光，中景，中心构图，暖色调，浅景深，镜头缓慢<推进/右移>。
<场景描述：真实生活空间>中，<人物简述>自然地<使用动作> @图片1 的商品，动作从容不刻意，
@图片1 在画面中占据<中景约三分之一>的稳定位置，正面朝向镜头一侧。
环境音包括<环境音清单>；全片无台词，配有轻柔的<风格>背景音乐。
商品轮廓与包装文字保持清晰完整，人物与商品的相对大小比例全程稳定，画面干净无叠加图形。
```

**要点**：种草片最容易丢商品 —— **必须写死商品的画面占比与朝向**，否则 8 秒后商品被镜头晃出画。

## 8. 老素材改造 / 续拍（视频编辑 V2V）

**形态**：`reference_video`（原片）+ 可选 `reference_image`（新元素）
**推荐参数**：`duration` 按需（**输入视频时长 + 输出 duration ≤ 30s**）`audio` 随原片诉求

官方公式 = **编辑对象 + 编辑行为**。**只写要改的地方**，其余靠「其他保持不变」兜住。

```
# 换 SKU / 换色
把视频中的<商品>换成 @图片1 中的<新款>，其他保持不变。

# 模特换装（多图按顺序编号）
让视频中的模特穿上 @图片1 中的外套和 @图片2 中的裤子。

# 换背景 / 换氛围
把背景改为浅灰无缝影棚，其他保持不变。
视频修改为暖色调圣诞氛围，加入暖黄串灯光斑，其他保持不变。

# 加/删元素
桌面右侧添加一枝新鲜薄荷，其他保持不变。
去除台面左侧的杂物。

# 改口播词（务必保音色）
保持人物音色和语气，将主播的说话内容改为："现在下单立减三十"。

# 加动作
让视频里的主播拿起商品，旋转展示背面。

# 视频延长（只写后续动态）
主播继续讲解，把商品放回桌面并双手比出爱心。

# 风格化
把视频改为 2D 卡通风格。
把视频改为图中的插画风格。
```

**电商 V2V 翻车点**：
- 换 SKU 的参考图**必须同角度同光位**，否则接缝明显（最高频翻车点）
- **色号敏感品类（口红、粉底、油漆、布料）不要走全局调色**，会连带改掉商品本色，改用元素替换或重拍
- 改台词漏写「保持人物音色和语气」= 音色必漂
- 视频延长时**不要复述已有画面**，否则模型会从头再演一遍

## 9. 品牌 TVC / 创意反转广告

**完整写法见 [`brand-tvc-blueprint.md`](brand-tvc-blueprint.md)**，这里只列骨架。

**形态**：T2V（无素材）或 全能参考（商品图/演员图）
**推荐参数**：`duration` **以客户指定为准**（常见 15–30s），`ratio` 按投放渠道，`audio=true`（同步现场声是质感的一半）

套用步骤：
1. 六拍骨架按实际 `duration` 等比切分（≤10s 砍掉反转只留三拍），时间戳求和 = `duration`
2. 反转机制六选一，反转前埋一个可见线索，落点必须是商品
3. 商品连续性锁八查 + 演员锁（含手部使用：谁拿、哪只手、是否换手）
4. 声音层默认「无背景音乐」+ 与画面同步的现场声；客户要 BGM 才写
5. 零 logo / 白牌需求 → 逐位置正向覆盖（blueprint §5），并提醒参考图带标时需先修图
6. 多版本 → 版本间至少改三项（机制/镜头逻辑/场景策略），每条写全不写「同上」

**要点**：客户已有脚本/提示词时，本模板只补技术层，叙事结构、动作、台词一律以客户原稿为准（SKILL §1.1）。

## 通用组合速查

| 想要的效果 | 往前缀里塞 |
|---|---|
| 高级感 | 柔光，侧光，浅景深，低饱和度，长焦镜头 |
| 通透干净 | 日光，晴天光，柔光，高亮度，浅灰无缝背景 |
| 食欲感 | 暖色调，硬光点缀，微距，高饱和度，边缘光 |
| 科技感 | 冷色调，硬光，低饱和度，高对比度，黑镜反射 |
| 生活流 | 日光，柔光，中景，手持轻微呼吸感，浅景深 |
| 戏剧张力 | 高对比度，硬光，边缘光，低角度拍摄，暗背景 |
