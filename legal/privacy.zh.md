# 隐私政策

**版本 1.1 · 生效日期：2026 年 8 月 28 日**（本版本为澄清性修订，即时生效；版本 1.0 自 2026 年 8 月 17 日起适用）

本政策说明 deepseek-harness-cloud（站点 https://dshcloud.online ，下称「本服务」）如何收集、使用、共享与保护您的个人信息。

## 2. 我们收集哪些信息

### 2.1 您主动提供的

| 类别 | 具体内容 |
|---|---|
| 账号标识 | 邮箱地址；若使用第三方登录，则为 Google 或 GitHub 返回的账号标识与邮箱 |
| 认证凭据 | 密码（以加盐 scrypt 哈希存储，**我们无法还原明文**）、邮箱验证码（哈希存储） |
| 资料 | 显示名称 |
| 您的内容 | 您向智能体提交的指令、上传或生成的文件、会话记录 |
| 沟通记录 | 您发给上述邮箱的邮件内容 |

### 2.2 使用服务时自动产生的

| 类别 | 具体内容 |
|---|---|
| 访问日志 | IP 地址、请求路径、HTTP 状态码、时间戳、User-Agent |
| 大致地理位置 | 由 IP 推断的国家/地区（经 CDN 提供），**非精确定位** |
| 用量记录 | 模型调用的 token 数、扣减的积分、云端工作台的活跃分钟数 |
| 设备记录 | 桌面客户端的设备授权记录（设备名、平台、最后活跃时间） |
| 限流计数 | 用于防滥用的计数器 |

### 2.3 我们明确不收集的

精确地理位置、通讯录、生物识别信息、广告标识符、跨站追踪数据。**我们不投放广告，站点不使用第三方广告或社交追踪脚本。**

### 2.4 支付信息

**您的银行卡信息由 Waffo Pancake 直接采集与处理，依 PCI-DSS 标准执行，不会传输至或存储于我们的服务器。** 我们仅从其接收订单号、金额、币种、支付状态与卡号后四位，用于对账与开票。

**我们不会将您的内容用于训练我们自己的模型**，除非您就特定内容另行明确同意。

## 4. 我们与谁共享

**我们不出售您的个人信息，也不为广告目的共享您的个人信息。**

为运行服务，以下类别的服务商会处理相应数据：

| 服务商 | 处理内容 | 所在地 |
|---|---|---|
| Waffo Pancake（登记商户与支付处理方） | 支付与税务信息 | 见其隐私政策 |
| 千面 AI 网关（api.qianmian.ai） | 您提交给模型的输入与模型输出 | 新加坡 |
| 上游模型服务商（经上述网关）：Anthropic、OpenAI、Google、DeepSeek、阿里巴巴、月之暗面、智谱、MiniMax、字节跳动、小米、xAI | 您提交给模型的输入与模型输出 | 各自所在地 |
| 阿里云百炼（模型服务） | 您提交给模型的输入与模型输出 | 中国（北京） |
| 智谱（联网搜索） | 您的搜索查询词 | 中国 |
| Resend（邮件送达） | 收件邮箱地址、邮件正文 | 美国 |
| Cloudflare（CDN、R2 对象存储、DNS） | 访问日志、安装包分发 | 全球边缘节点 |

我们与上述各方签有数据处理相关条款，仅在提供服务所必需的范围内共享。

**关于阿里云百炼**：部分图像与视频生成能力（如生图、图像编辑、视频生成）由阿里云百炼直接提供，不经千面网关中转。选择这些模型时，您的输入与生成结果会在**中国境内（北京）**的服务器处理。其余模型不受影响。您可以通过不选择这些模型来避免该项传输。

此外，在下列情形我们可能披露信息：依据有约束力的法律程序；为保护本服务、用户或公众的权利与安全；发生并购或资产转让时（我们将提前通知并确保受让方承担同等义务）。

## 5. 跨境传输

我们的服务器位于**新加坡**，运营主体位于**中国**，上述服务商分布于多个法域。因此您的数据会发生跨境传输。

保障措施：与接收方签订包含数据保护义务的合同条款；传输全程使用 TLS 加密；按最小必要原则限制各服务商可见的数据范围。若您位于欧洲经济区、英国或瑞士，可向 legal@agentsdance.ai 索取所适用的传输机制说明。

## 6. 保留期限

| 数据类型 | 保留期限 |
|---|---|
| 账号标识与资料（邮箱、显示名、密码哈希） | 注销时**立即**抹除 |
| 设备授权记录、登录验证码、组织成员关系 | 注销时**立即**删除 |
| 邮箱验证码（未注销时） | 10 分钟后失效并清除 |
| 限流计数器 | 最长 24 小时 |
| 访问日志 | 滚动保留，上限 100 MB（按当前流量约一个季度），超出后最旧部分被自动覆盖 |
| 用量与扣费记录 | 5 年（对账与税务需要）。注销后这些记录仅保留用户编号，不含您的联系方式 |
| 支付记录 | 依税务法规，至少 5 年（由 Waffo Pancake 与我方各自留存） |

超出上述期限后，数据将被删除或不可逆匿名化。

**注销的实际效果**：您在控制台注销账号时，我们立即抹除您的邮箱、显示名与密码哈希，删除全部设备授权、登录验证码与组织成员关系，并使所有会话立即失效。依法必须留存的扣费与支付记录会保留，但其中不再包含可识别您的联系方式。

## 7. 您的权利

无论您位于何地，您均可行使以下权利：**访问、更正、删除、导出（可携带）、限制处理、反对处理、撤回同意**。

- 大部分操作可直接在控制台完成（修改资料、撤销设备授权、注销账号）；
- 其余请发送邮件至 legal@agentsdance.ai；
- **我们在收到请求后 30 个自然日内答复**；情况复杂需延长的，我们会在该期限内说明理由。

若您位于欧洲经济区/英国，您有权向所在地监管机构投诉。若您为加利福尼亚州居民，您享有 CCPA/CPRA 下的知情、删除、更正与拒绝出售/共享的权利——如上所述，**我们不出售也不为定向广告共享个人信息**。行使权利不会导致您受到差别待遇。

## 8. 安全

传输层全程 TLS；密码以加盐 scrypt 哈希存储；会话令牌签名并可随时吊销；云端工作台为每位用户提供独立容器，具备内存、CPU、进程数限制与网络隔离；模型服务商的密钥仅保存在服务端，**任何情况下都不会下发到客户端**。

尽管如此，没有任何系统能保证绝对安全。**若发生可能危及您权益的数据泄露，我们将在知悉后 72 小时内通知受影响用户及适用的监管机构。**

## 9. 未成年人

本服务面向 **18 周岁以上**用户。我们不有意收集未满 18 周岁者的个人信息。若您认为我们误收了此类信息，请联系 legal@agentsdance.ai，我们将予以删除。

## 10. Cookie 与同类技术

我们仅使用**必要的** Cookie：会话 Cookie（保持登录状态）与安全 Cookie（防跨站请求伪造）。**我们不使用广告 Cookie、不做跨站追踪、不接入第三方分析脚本。** 因此站点没有 Cookie 同意横幅——没有需要征得同意的非必要 Cookie。

## 11. 营销邮件

我们默认只发送**服务类邮件**（验证码、账单、安全提醒、重大条款变更），这类邮件与账号功能相关，无法退订。若我们未来发送产品营销邮件，将单独征求同意，并在每封邮件中提供一键退订链接；退订不影响服务类邮件的送达。

## 12. 政策变更

本政策如有重大变更，我们将于**生效前至少 15 天**通过站内公告与您的注册邮箱通知。非重大的措辞修订将直接更新本页并变更下方日期。
