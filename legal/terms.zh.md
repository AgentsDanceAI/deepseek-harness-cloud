## 2. 服务内容

本服务在开源项目 DeepSeek Harness（MIT 许可）之上提供托管的账号、额度与模型网关，包含三部分：

1. **云端 Harness**：浏览器中即可使用的云端智能体工作台，每位用户运行在独立容器中；
2. **桌面 Harness**：macOS 与 Windows 客户端，任务在您本机执行；
3. **统一模型网关**：由我们代为向上游模型服务商采购并调用，您无需自行申请 API Key。

**本服务由我们独立运营，与 DeepSeek（杭州深度求索人工智能基础技术研究有限公司）无任何隶属、代理或合作关系，亦非其官方产品。** 「DeepSeek」与「DeepSeek Harness」为其各自权利人所有。

## 4. 积分、机时与计费方式

4.1 **两种独立额度。** 积分用于计量模型调用（按 token 计算），机时用于计量云端工作台的运行时长（仅按智能体**实际执行任务**的分钟计，闲置不计费）。两者互不折算、互不占用。

4.2 **积分扣减规则。** 每个模型有公开的倍率，以 Claude Sonnet 为 1.00x 基准；1.00x 相当于每 100 万 token 扣 1000 积分。完整倍率表实时公示于 https://dshcloud.online/pricing 。倍率随上游价格调整时，我们会在生效前于该页面更新。

4.3 **免费额度。** 注册即赠一次性积分（当前为 500 积分），另含每月 3 小时云端机时（按自然月重置）。免费额度不可提现、不可转让。

**本服务不进行自动续费，也不会产生任何周期性扣款。** 每一次付费都是**单次、一次性**的交易：

- 您购买某个套餐周期（月度或年度），我们即为您的账号增加相应天数的权益；
- 周期结束后，账号**自动回落至免费版**，我们不会再次向您扣款；
- **除非您主动再次下单，我们永远不会向您的支付方式发起第二次扣款。**

因此本服务不存在「订阅取消」流程——没有需要取消的东西。您可以随时停止购买。
