# 许可记录

[English](README.md) | [简体中文](README.zh-CN.md)

本目录记录当前许可证和不含秘密信息的来源证明。

| 文件 | 用途 |
|---|---|
| `LICENSE_STATE.toml` | 机器可读的当前许可证与生效版本 |
| `COMMUNITY_BASELINE.manifest` | 初始 Community 基线的公开源码清单 |
| `COPYRIGHT_INVENTORY.csv` | 按路径记录的权利归属和第三方来源审核台账 |

控制性许可文本为 [LICENSE](../../LICENSE)，仓库级说明见
[LICENSING.md](../../LICENSING.zh-CN.md)。

不得仅凭提交作者、仓库位置、雇佣关系推测或生成文件头判断版权归属。保密证明
应存放在受控系统中，本目录只记录不含秘密的标识和结论。
