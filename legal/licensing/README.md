# Licensing records

[English](README.md) | [简体中文](README.zh-CN.md)

This directory records the active license and non-secret provenance evidence.

| File | Purpose |
|---|---|
| `LICENSE_STATE.toml` | Machine-readable active license and effective release |
| `COMMUNITY_BASELINE.manifest` | Inventory of the public source tree at the initial Community baseline |
| `COPYRIGHT_INVENTORY.csv` | Per-path ownership and third-party provenance review ledger |

The controlling license is [LICENSE](../../LICENSE). The repository-level
explanation is [LICENSING.md](../../LICENSING.md).

Do not infer ownership from a commit author, repository location, employment
assumption, or generated-file header. Confidential evidence stays in an
access-controlled record system; this public directory contains only non-secret
identifiers and conclusions.
